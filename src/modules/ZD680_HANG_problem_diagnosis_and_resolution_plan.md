## 1. 文档目标

当前系统已经形成可运行的：

```text
二阶 LADRC-X/Y
+ 原生 PID-Z
+ 绳长相关带宽约束
+ 能量抗摆
+ PX4 原生姿态/角速度 PID
+ Gazebo 吊挂状态闭环
```

但在统一 `0.5 N / 6 s` 负载外扰场景中，完整方案尚未超过原生 PID。本计划的目标不是立即扩大实验数量，而是按最少的必要步骤定位和消除主要矛盾，使系统依次达到：

1. 控制方向、相位和能量流一致；
2. 外扰期间不主动放大摆动；
3. 恢复段不长时间争夺和耗尽水平加速度；
4. 名义场景至少接近 PID；
5. 参数变化和复合扰动下体现 LADRC、频率感知和能量抗摆的组合价值。

本计划暂不直接修改代码。所有结构改动均先给出触发条件、公式、日志需求、验证指标和停止条件。

## 2. 当前核心结论

截至 `090716`，可以把当前状态概括为：

```text
能量抗摆模块本身有效；
基础 LADRC 在外扰阶段平均向摆动输入能量；
抗摆在外扰阶段没有完全抵消该能量输入；
外扰结束后 LADRC 与抗摆都能消能，但位置恢复与抗摆争夺控制余量；
整体降低 LESO 带宽能改善摆动频段相位，却明显损失低频位置抗扰；
原生 PID 以更小的控制量获得更小的位置误差和摆角峰值。
```

因此最主要的研究矛盾不是“抗摆有没有用”，而是：

> 同一个水平加速度通道同时承担低频位置抗扰和吊挂频段能量控制，当前 LESO、基础 LADRC、抗摆和执行环节之间没有完成频率与能量责任分配。

## 4. 问题 P1：外扰阶段基础 LADRC 注入摆动能量

### 4.1 现象

`090716` 外扰阶段的命令能量功率：

```text
P_LADRC = +0.00854
P_AS    = -0.00335
P_final = +0.00519
```

定义：

```text
P = -L * a_body · theta_dot_body
```

因此：

- 基础 LADRC 平均向摆动输入能量；
- 抗摆平均消耗能量；
- 抗摆制动力度小于基础项的激励；
- 最终命令在外扰期间仍平均增加摆动能量。

PID 基线在同阶段的真实机体加速度控制贡献为负值，说明PID没有额外推高摆动，尽管负载外力本身仍使总能量增长。

### 4.2 当前根因假设

高置信度假设：

1. 吊挂反作用进入位置/速度测量后，被 LESO 视为总扰动的一部分；
2. LESO扰动补偿和状态估计在 `0.6～0.7 Hz` 附近仍有明显响应；
3. 加速度指令经过姿态环、推力和机体—吊挂耦合后产生额外相位滞后；
4. 基础位置控制在部分摆动相位上追逐机体位置误差，形成对负载的不利基座运动。

### 4.3 对应解决路径 A：摆频附近限制 LADRC 扰动补偿

第一结构候选是只处理 LESO 扰动补偿：

```text
u_nominal = wc^2*(x_sp-z1)/b0
          + 2*wc*(v_sp-z2)/b0

u_dist_raw = -z3/b0

u_LADRC = u_nominal + u_dist_selected
```

其中 `u_dist_selected` 不再直接等于 `u_dist_raw`，而是经过绳长相关的频率选择环节。

候选实现 1：摆频陷波。

```text
H_notch(s) =
  (s^2 + 2*zeta_z*omega_n*s + omega_n^2)
  ------------------------------------------------
  (s^2 + 2*zeta_p*omega_n*s + omega_n^2)

u_dist_selected = H_notch(s) * u_dist_raw
```

当 `zeta_z < zeta_p` 时，`omega_n` 附近衰减，远低于固有频率的扰动补偿基本保留。

候选实现 2：只保留低频扰动分量。

```text
z3_LF = LPF(z3, f_cut)
u_dist_selected = -z3_LF/b0
```

候选实现 3：互补分解。

```text
z3 = z3_LF + z3_swing + z3_HF

z3_LF       -> LADRC扰动补偿
z3_swing    -> 只记录，不由LADRC直接抵消
z3_HF       -> 抑制
```

计划优先顺序：先验证只处理 `z3` 的最小改动。如果摆频能量仍主要来自 `z1/z2`估计和位置反馈，再扩大到观测创新或名义控制项。

### 4.4 需要新增的诊断量

```text
z3_raw_x/y
u_dist_raw_x/y
u_dist_selected_x/y
notch/LPF state
estimated swing frequency or scheduled omega_n
P_nominal
P_dist_raw
P_dist_selected
```

### 4.5 验证标准

统一外扰阶段：

```text
mean(P_final) <= 0
mean(P_LADRC) 显著低于当前 +0.00854
外扰净能量增量 < 当前完整方案 0.2242
摆角峰值 < 当前 16.55 deg
```

同时要求低频位置误差不退化到 `wo=2.02` 的当前水平。

## 5. 问题 P2/P5：统一降低 `wo` 无法兼顾位置与摆动

### 5.1 现象

关闭抗摆时：

```text
wo_eff: 3.234 -> 2.021 rad/s

恢复最后3 s摆角 RMS: 12.109 -> 8.978 deg
外扰结束能量:        0.2550 -> 0.1740

外扰 XY RMS:         0.0921 -> 0.1462 m
恢复 XY RMS:         0.1291 -> 0.2386 m
```

降低 `wo` 改善了摆动频段相位，却减弱了低频外力估计和位置恢复。

### 5.2 当前频率约束的真实作用

当前：

```text
wc_eff = min(wc_base, r_c*omega_n)
wo_eff = max(r_min*wc_eff, min(wo_base, r_o*omega_n))
```

它只是在所有频率上共同改变一个观察器带宽，并没有区分：

```text
低频恒力/风扰
吊挂固有频率
高频噪声
```

### 5.3 对应解决路径

将“绳长相关标量带宽”扩展为“绳长相关频率选择特性”：

```text
低频段：保留外扰估计和位置补偿
摆动段：降低LESO/LADRC直接补偿
高频段：保持噪声抑制
```

绳长调度中心仍由：

```text
omega_n = sqrt(g/L)
```

提供，但频率调度对象从单一 `wc/wo` 扩展到滤波中心、带宽和衰减深度。

### 5.4 代码前的参数级折中验证

在进入结构修改前，只保留一组中间观察器带宽作为诊断点：

```sh
param set MC_HANG_WO_R 0.60
param set MC_HANG_WO_MIN 2.0
```

当 `L=0.6 m`、`WC_R=0.25` 时：

```text
wc_eff ≈ 1.01 rad/s
wo_eff ≈ 2.43 rad/s
```

该组只用于确认位置—摆动折中曲线是否连续，不作为解决结构性冲突的最终方案。

### 5.5 参数级验证的停止条件

如果中间 `wo` 仍表现为：

- 位置改善同时摆动恶化；或
- 摆动改善同时位置恶化；或
- 外扰阶段 `P_final` 仍为正；

则停止继续密集扫描 `wo`，将问题归入频率选择和控制协调，而不是继续全局带宽试错。

## 6. 问题 P3：位置恢复与抗摆争夺水平加速度

### 6.1 现象

`090716` 外扰结束后的前 3 s：

```text
最终加速度 P95 = 0.8 m/s^2
接近总上限的样本比例 ≈ 49.9%
抗摆输出 P95 = 0.2 m/s^2
位置峰值 ≈ 0.46 m
```

当前合成器优先保留抗摆请求，基础位置控制使用剩余二维加速度空间。

### 6.2 当前根因假设

1. 外扰期间产生了过多摆动能量和位置偏差；
2. 外扰结束后两个目标同时需要较大水平加速度；
3. 总包络和抗摆单项上限同时激活；
4. 当前分配只考虑加速度范数，没有显式考虑位置误差、能量功率和执行相位。

### 6.3 对应解决路径 A：总能量功率监督

定义候选总命令：

```text
a_candidate = a_LADRC + a_AS
P_candidate = -L * a_candidate,body · theta_dot_body
```

当摆动能量超过有效阈值且 `P_candidate>0` 时，计算沿摆速方向的最小修正：

```text
lambda = max(
    0,
    [-P_allow/L - a_candidate·theta_dot]
    / [||theta_dot||^2 + epsilon]
)

a_passive = a_candidate + lambda*theta_dot
```

当 `P_allow=0` 时，该投影消除预测到的正能量输入。二维中与摆速正交的加速度分量仍可用于位置控制。

该公式只描述计划中的数学约束。实际实现还需要处理：

- body/NED坐标转换；
- 低摆速时的数值保护；
- 能量门控；
- 总加速度限幅；
- 实际执行相位；
- 外扰直接作用于负载时的功率解释。

### 6.4 对应解决路径 B：动态控制权分配

将固定“抗摆优先”扩展为与状态相关的权重：

```text
minimize:
    w_pos(E, e_pos) * ||a-a_LADRC||^2
  + w_as(E, theta_dot) * ||a-a_AS_target||^2

subject to:
    ||a|| <= a_total,max
    P_predicted <= P_allow
```

在实现复杂度上，可分为：

1. 标量权重混合；
2. 沿摆速/垂直摆速方向的解析投影；
3. 二维小规模约束优化。

优先验证解析投影，因为它的物理意义和日志验证最直接。

### 6.5 验证标准

```text
恢复前3 s的0.79 m/s²以上占比 < 20%
恢复段位置 RMS 显著低于当前 0.305 m
恢复最后3 s摆角 RMS 不高于当前 2.50 deg
恢复最后3 s能量不高于当前 0.0111
```

## 7. 问题 P4：LESO输入未包含真实执行动态

### 7.1 现象

当前 `_last_applied_acceleration` 由最终推力设定值反算：

```text
a_applied,xy = thrust_sp,xy * g / hover_thrust
```

该信号已经考虑命令合成和推力饱和，但没有包含：

- 姿态环响应时间；
- 角速度环和电机动态；
- 机体惯性；
- 吊挂反作用；
- 实际机体水平加速度相位。

最近相位拟合中，命令到真实机体加速度在摆动频段存在约50～60°附加相位差。

### 7.2 对应解决路径 A：一阶执行动态模型

对 LESO 已知输入加入识别得到的一阶模型：

```text
tau_a * a_model_dot + a_model = a_command
u_obs = a_model
```

`tau_a` 由无吊挂或小摆角条件下的加速度命令—真实加速度数据辨识。该方案保留低噪声命令输入，但显式承认执行滞后。

### 7.3 对应解决路径 B：滤波实际加速度

使用 PX4 估计或 Gazebo 可验证的真实水平加速度：

```text
u_obs = LPF(a_measured, f_acc)
```

需要同时评估：

- 噪声；
- EKF延迟；
- 重力与姿态补偿；
- NED坐标一致性；
- 额外低通相位；
- SITL 与实机传感器可迁移性。

### 7.4 对应解决路径 C：命令与测量融合

```text
u_obs = alpha*a_model + (1-alpha)*a_measured_filtered
```

命令路径提供低噪声快速预测，测量路径校正长期偏差。该方案复杂度高于一阶模型，不作为第一个结构试验。

### 7.5 验证步骤

1. 先离线比较三种 `u_obs` 与真实加速度的幅值、相位和延迟；
2. 在不闭环替换 LESO 输入的情况下记录候选信号；
3. 确认候选输入在0.05～1 Hz内的相位和噪声；
4. 再进入闭环 A/B 对比。

## 8. 问题 P6：初始条件不一致

### 8.1 现象

近期统一外扰前摆角 RMS：

```text
PID:             0.186 deg
完整高wo:        1.431 deg
无抗摆高wo:      4.945 deg
无抗摆低wo:      3.521 deg
完整低wo:        0.696 deg
```

初始能量差异会影响外扰峰值、相位、能量增量和恢复时间。

### 8.2 对应解决路径

记录器增加或严格执行初态条件：

```text
theta_RMS(pre_window) <= threshold_angle
E_mean(pre_window)     <= threshold_energy
|v_xy|                 <= threshold_velocity
position error         <= threshold_position
yaw error              <= threshold_yaw
持续满足时间            >= threshold_time
```

如果某个控制配置无法在最大等待时间内满足条件，应记录为该配置的悬停/初态性能结果，而不是静默等待到任意时刻开始外扰。

### 8.3 报告规则

每组强制同时报告：

```text
外扰前摆角 RMS、峰值、能量均值和末值
外扰绝对峰值
外扰净能量增量
相对初始能量的归一化变化
恢复段固定窗口指标
```

## 9. 问题 P7：原始抗摆被动性不能覆盖完整闭环

### 9.1 当前证明范围

原始能量抗摆满足：

```text
a_AS,raw = kd*sigma_E*theta_dot

E_dot_AS,raw
  = -L*kd*sigma_E*||theta_dot||^2
  <= 0
```

该结论不包含：

- 斜率限制；
- 激活渐入；
- NED合成；
- 基础LADRC；
- 总加速度限幅；
- 姿态与电机相位；
- 外力功率。

### 9.2 对应解决路径

把能量验证从“抗摆单项”扩展为四级：

```text
P_AS_raw
P_AS_applied
P_base
P_final_command
P_actual_base_acceleration
```

同时记录：

```text
P_external（仿真中可由外力与负载速度计算）
E_dot_observed
```

形成能量平衡核对：

```text
E_dot_observed
≈ P_external
 + P_actual_base
 + P_damping/model_loss
```

该核对用于区分控制器输入、外力做功、模型阻尼和数值误差。

## 10. 问题 P8：为什么PID当前更好，以及超越条件

### 10.1 PID当前优势

统一场景：

```text
PID外扰XY RMS:       0.079 m
完整090716:           0.179 m

PID摆角峰值:         11.49 deg
完整090716:           16.55 deg

PID外扰净能量增量:   0.0926
完整090716:           0.2242

PID外扰加速度P95:    0.449 m/s^2
完整090716:           0.666 m/s^2
```

PID不是因为控制量更大而更好，而是当前闭环相位、阻尼、抗饱和和PX4内环匹配更成熟。它没有显式追逐每一个吊挂周期扰动，因此没有在外扰阶段产生同等程度的基座激励。

### 10.2 超越PID的分阶段定义

#### 阶段 A：名义场景可比

至少满足：

```text
位置 RMS 不超过 PID 的 120%
摆角峰值不超过 PID 的 120%
恢复末端能量不高于当前完整方案
无 safety abort
总加速度饱和比例可接受
```

#### 阶段 B：名义场景不劣

```text
位置 RMS <= PID * 1.10
摆角峰值 <= PID * 1.10
恢复时间或能量积分至少一项优于 PID
控制量没有依靠长期饱和换取结果
```

#### 阶段 C：体现组合方法优势

## 17. 风险与回退原则

### 17.1 频率选择风险

- 滤波器本身带来相位；
- 绳长参数错误导致中心频率错误；
- 过深衰减可能削弱真实周期外扰补偿；
- 参数更新时滤波状态可能产生瞬态。

回退：新功能必须有独立开关，关闭后恢复当前 `z3` 直接补偿。

### 17.2 能量监督风险

- 摆速很小时除法敏感；
- 测量噪声引起控制抖动；
- 预测功率与真实功率存在执行相位差；
- 过强投影可能牺牲位置控制。

回退：能量阈值、摆速阈值、输出渐入、独立开关和总加速度限幅必须保留。

### 17.3 实际加速度输入风险

- EKF或传感器噪声进入高增益LESO；
- 滤波又增加相位；
- SITL地面真值不能直接代表实机信号；
- 坐标、重力补偿或时间戳不一致。

回退：先影子记录，不直接闭环；保留推力反算输入路径。

### 17.4 试验解释风险

- 初始能量不一致；
- 记录器参数被截断；
- 外扰实体或坐标系错误；
- 只使用单次结果；
- 通过增加控制饱和获得表面指标改善。

回退：metadata、events、参数快照、初始条件和饱和率作为每组有效性检查。

## 18. 计划实施顺序

按依赖关系排序：

1. 冻结分析口径、初态指标和统一外扰命令；
2. 只跑一次 `wo_eff≈2.43 rad/s` 的中间诊断；
3. 固定问题是否属于全局带宽权衡；
4. 增加频率选择模块及所需日志；
5. 完成频率选择关闭/开启的单元测试和消融；
6. 与能量抗摆组合，检查外扰阶段总功率；
7. 若仍存在正功率或恢复饱和，引入能量监督/分配消融；
8. 若命令功率正确而真实功率异常，再处理LESO执行输入模型；
9. 名义场景达到可比后，扩展绳长、质量和扰动矩阵；
10. 最后形成重复统计和论文级对比。

该顺序的核心约束是：

```text
先确认能量流方向；
再处理位置与抗摆的控制权；
再处理执行模型；
最后扩展实验规模。
```

## 19. 预期形成的控制结构描述

本计划最终要验证的不是某一个固定实现，而是以下责任边界是否成立：

```text
低频位置与慢变外扰
        -> 二阶LADRC/LESO

吊挂固有频段
        -> 能量抗摆主导

最终加速度合成
        -> 总包络 + 能量功率一致性

执行动态
        -> LESO已知输入模型与真实机体响应一致
```

只有当上述责任边界分别得到日志和消融支持时，才能把“频率感知二阶LADRC＋能量抗摆”作为一个完整方法，而不是若干控制项的简单叠加。
