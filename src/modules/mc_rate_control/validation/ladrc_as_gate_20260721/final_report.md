# ZD680 吊挂四旋翼“内环 LADRC + 外环 AS”一次性验证报告

## 1. 一句话结论与唯一决策枚举

六组受限 D0 整定均无法让角速度 LADRC 建立任务书要求的正式初态，且诊断窗口显示明显 roll/pitch 角速度波动、控制努力与吊载摆动，故本路线拒绝并保持 PID+AS 强基线：`C_REJECT_LADRC_AS_KEEP_PID_AS_BASELINE`。

## 3. 代码、控制链和挂点几何审计结果

### 控制链

实际结构为：PX4 位置/速度 PID → PX4 姿态环 → PID 或一阶角速度 LADRC → yaw 输出低通/电池缩放 → 归一化 `vehicle_torque_setpoint` → 控制分配器/电机。AS 开启组在水平加速度命令路径使用同一冻结的能量 AS。

LADRC 使用一阶对象 `ω_dot=b0*u+f`、二阶 LESO：`z1_dot=z2+b0*u_applied+2*wo*(ω-z1)`、`z2_dot=wo²*(ω-z1)`，控制律 `u_raw=[wc*(ωsp-z1)-z2]/b0-D*ω_dot`，随后按轴本地限幅。`u` 是归一化力矩；`z2` 是 rad/s² 量纲的总扰动估计，不是已标定的 N·m。

控制周期来自 `vehicle_angular_velocity.timestamp_sample`，限制为 0.125～20 ms。LESO 读取的是所有后处理后实际发布的上拍归一化力矩。分配器饱和时冻结 `z2_dot`。PID→LADRC 使用当前速率/设定/上拍力矩无扰切换初始化；反向切换清 PID 积分。TD、RBF、PAS、VFB 和位置外环 LADRC 均确认关闭。

现有开关是三轴统一开关，C1/C3 的 yaw 也切换到了 LADRC。未向 yaw 注入扰动，后文列出 yaw 诊断，但本结论只针对 roll/pitch。

### 几何

- `base_link` 主体质量 1.72 kg，`Ixx=Iyy=0.0105 kg·m²`、`Izz=0.0200 kg·m²`，惯性原点为 link 原点。
- 四个 rotor link 各 0.12 kg，关于水平面对称、z=+0.06 m；计入后无人机自身总质量 2.20 kg，聚合质心约 `[0,0,+0.0131] m`（Gazebo FLU）。
- 挂点 `[0,0,-0.20] m`（相对 base_link），所以相对无人机聚合质心 `r_h≈[0,0,-0.2131] m`（FLU）。
- 绳长 0.60 m，payload 0.50 kg，绳 0.010 kg，gimbal 0.005 kg。
- 竖直绳张力与 `r_h` 平行时力矩近零；有水平张力分量时 `tau_L=r_h×T_L` 产生 roll/pitch 力矩。挂点并非与质心重合。

详细源码位置、坐标变换和边界见 `code_audit.md`。

- T4/T5 水平加速度总预算饱和占比 44.2%/59.5%；其余组为 0。它与 T4/T5 的大位置速度和摆动一致。
- 所有 9 次分析窗口 `vehicle_status.failsafe=0`、failure detector=0；均正常 LAND 并解除武装。没有碰撞或落地异常证据。
- 没有记录绳张力直接测量，故不能单独验证“绳松弛”；关节连续、负载未碰地、无安全标志，但不把缺少张力传感器写成已证明无松绳。

结论是：失败并非执行器饱和，而是当前一阶 LADRC 参数/结构在吊挂闭环中产生了不可接受的速率波动和摆动。增加控制权限不是合理修复方向。

## 12. 外力与外力矩作用通道的物理解释

现有工具对 `zd680_hang_0::base_link` 的 persistent `EntityWrench` 发送 force（N）与 torque（N·m）。消息没有额外作用点字段，故工具不会为纯力人为附加 `r×F`；纯 roll/pitch torque 直接进入姿态匹配扰动通道。

坐标约定：Gazebo world 为 ENU；PX4 local 为 NED；body 输入按 PX4 FRD，仅用当前 yaw 投影到 NED 后转 ENU。变换为 `(N,E,D)→(E,N,-D)`，发布值会写入事件/live CSV。

- 质心附近水平外力主要进入平动 → 位置 PID/AS 通道；不能单独证明角速度 LADRC。
- 直接 roll/pitch 力矩主要进入角速度内环，是 Stage 2 应验证的匹配扰动。
- 当前挂点相对质心向下约 0.213 m；摆动时水平绳张力通过 `r_h×T_L` 形成 roll/pitch 力矩，也会通过机体/挂点运动与摆动能量耦合。
- 即便未来 LADRC 改善纯力矩姿态，也不能自动归因成“抑制了全部吊载扰动”；需要 C2/C3 有效配对证明系统级摆动没有恶化或得到改善。

本轮没有实际外扰运行，所以上述是物理与接口审计，不是幅值、作用时刻或 LESO 对齐的实验结论。

## 13. 哪些结论可以用于论文，哪些不能

可以用于内部方案筛选/负结果记录：

- 在当前 ZD680 SITL、当前一阶角速度 LADRC 实现和六组受限 D0 参数范围内，LADRC 无法建立任务书要求的标称初态；
- PID 与 PID+AS 能在同一仿真/日志流程通过严格门禁，因此拒绝不是由构建或时序无效造成；
- T0 是六组中相对最不差的候选，但仍有显著 roll/pitch 波动、控制变化和吊载摆动；
- 当前内环 LADRC 不应成为该论文的候选主方案，工程主基线应保持 PID+AS。

不能用于论文的表述：

- 不能称 LADRC 在外力矩下改善，因为 D-T 未运行；
- 不能称 LADRC+AS 改善抗摆，因为没有有效 C2/C3 配对；
- 不能把不同门禁窗口的诊断比值写成正式改善率或显著性；
- 不能把 `z2` 称为精确 N·m 外力矩估计；
- 不能把质心水平外力效果归功于角速度 LADRC；
- 不能把 SITL 结果写成实机验证或北大核心录用证据；
- 不能在 Stage 1 失败后建议继续堆叠 RBF、TD、新观测器或无限扫参。

## 14. 下一步唯一建议

立即冻结 `PID+AS` 为工程与后续论文实验的主基线（本机持久 SITL 参数已恢复为 `MC_LADRC_EN=0`、`MC_HANG_AS_EN=1`）；停止继续开发本轮一阶内环 LADRC+AS 主线，把后续创新与正式重复实验资源集中到任务书允许的 AS 能量/功率协调或实验体系本身。
