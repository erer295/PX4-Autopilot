## 2. 当前完整控制结构

### 2.1 水平位置控制

当前论文路径使用：

```text
MC_PLADRC_EN=3
```

即：

```text
NED X/Y：二阶位置 LADRC
NED Z：原生 PX4 位置 P＋速度 PID
姿态/角速度内环：原生 PX4 PID
```

水平二阶 LADRC 可写为：

\[
u_{nom}=\frac{\omega_c^2(r-z_1)+2\omega_c(\dot r-z_2)}{b_0},
\]

\[
u_{dist,raw}=-\frac{z_3}{b_0},
\]

\[
u_{base}=u_{nom}+u_{dist,selected}.
\]

当前尚未实现 Z3 频率选择，因此：

\[
u_{dist,selected}=u_{dist,raw}.
\]

这意味着当前所谓“频率约束”只调度 LADRC 的控制器/观测器带宽，不对 `z3` 补偿做陷波或频带选择。

### 2.2 绳长频率约束

绳长为 \(L=0.6\,m\) 时，摆动自然频率为：

\[
\omega_n=\sqrt{g/L}\approx4.043\;rad/s,
\qquad f_n\approx0.643\;Hz.
\]

当前调度公式：

\[
\omega_{c,eff}=\min(\omega_{c,base},k_c\omega_n),
\]

\[
\omega_{o,eff}=\max(k_{o,min}\omega_{c,eff},
\min(\omega_{o,base},k_o\omega_n)).
\]

关键实验中的有效带宽：

```text
225058：wc_eff≈1.011 rad/s，wo_eff≈3.234 rad/s
090716：wc_eff≈1.011 rad/s，wo_eff≈2.021 rad/s
202007：wc_eff≈1.011 rad/s，wo_eff≈2.021 rad/s
```

### 2.3 能量抗摆

能量抗摆在航向对齐水平坐标系中使用滤波摆速：

\[
a_{AS}=2\zeta\sqrt{gL}\,\dot\theta\,\sigma_E,
\]

其中 \(\sigma_E\) 是能量门控。对机体水平加速度所引起的摆动功率，采用：

\[
P=-L\,a_h^T\dot\theta_h.
\]

因此理想情况下：

\[
P_{AS}=-2\zeta L\sqrt{gL}\,\sigma_E\|\dot\theta_h\|^2\le0.
\]

单元测试、反向/Y 轴/非零航向实验及有效 ULog 均支持当前抗摆符号正确。坐标轴符号不是现阶段完整方案不如 PID 的主要原因。

### 2.4 SHADOW 能量协调

候选控制量：

\[
a_c=a_{base}+a_{AS}.
\]

候选预测功率：

\[
P_c=-L a_c^T\dot\theta_h.
\]

当能量、摆速、正功率低通值和持续时间均满足门控时，SHADOW 计算：

\[
\lambda=\max\left(0,
\frac{-a_c^T\dot\theta_h}
{\|\dot\theta_h\|^2+\varepsilon}\right),
\]

\[
\Delta a_{shadow}=K_{pas}\,
\operatorname{sat}(\lambda\dot\theta_h).
\]

当前 SHADOW 不加入最终命令：

```text
MC_HANG_PAS_MD=1：计算并记录修正
passivity_active=0：最终闭环不变
```

所以 SHADOW 只能验证能量协调方向和幅值，不能证明实际摆角已经因 SHADOW 改善。

## 4. 为什么历史完整方案不如 PID

### 4.1 原因一：历史对比的初始摆动能量不公平

225058 与 225339 的外扰前摆角 RMS 分别为 1.43° 与 0.19°。吊摆系统的响应强烈依赖扰动施加时的相位和能量，初始能量相差近一个数量级时，后续峰值、恢复时间和位置误差不可直接归因于控制器。

早期多组实验还出现过：

- 起飞后吊载长期不能回到小摆角；
- 外扰开始前摆角仍有 3°～5°；
- 正反向、Y 轴和非零航向实验的外扰相位不同；
- recorder 只在动作序列开始前检查位置，未在真正 wrench 前重新检查；
- 文件夹标签与飞控实际参数或实体不完全一致。

因此，历史“PID 更好”有一部分是真实控制差距，另一部分来自实验前提不一致。

### 4.2 原因二：频率约束过于保守，位置误差积累后产生较大反向恢复命令

当前频率调度将位置控制带宽压到约 1.01 rad/s，显著低于摆频 4.04 rad/s；LESO 带宽也降到 2.02～3.23 rad/s。

这种做法的优点是减少快速追逐吊载运动，但副作用是：

1. 外扰初期位置恢复变慢；
2. 位置误差和 ESO 状态逐步积累；
3. 在恢复相位出现较大的 LADRC 命令；
4. 大命令又通过机体水平加速度重新激发吊摆；
5. 最终形成“位置误差—强恢复—再激摆”的循环。

225058 的恢复段命令 P95 达到 0.756 m/s²，而 PID 只有 0.352 m/s²；090716 的恢复早期直接触及 0.8 m/s² 总包络。这不是简单的“LADRC 参数太小”，而是过度降带宽后出现的延迟恢复与峰值控制并存。

### 4.3 原因三：正功率并不只来自 LESO 的 `z3` 补偿

202007 的有效控制量分解显示，在 wrench 窗口：

| 分量 | 正功率积分 | 负功率积分 |
|---|---:|---:|
| LADRC nominal | +0.03596 J/kg | -0.01816 J/kg |
| LADRC raw disturbance | +0.02428 J/kg | -0.01501 J/kg |
| 能量抗摆 applied | 0 | -0.02316 J/kg |
| 最终候选命令 | +0.04385 J/kg | -0.03994 J/kg |

注意：各分量的正功率积分不能简单相加得到最终值，因为它们在同一时刻可能符号相反。但是该分解明确说明：

- `P_nominal` 是重要且在该窗口更大的正功率来源；
- `P_dist_raw` 也会注能，但不是唯一来源；
- 抗摆分量保持耗能；
- 只对 `z3` 做陷波不能消除 nominal 项的注能。

因此，历史上继续降低 `wo` 或只削弱扰动补偿，最多缓解一部分问题，并会牺牲位置抗扰。真正需要的是 nominal、disturbance 和 anti-swing 之间的能量协调。

### 4.4 原因四：位置恢复与抗摆共享同一个水平加速度通道

当前执行链路最终只有一个二维水平加速度命令。位置 LADRC 希望迅速消除机体位置误差，能量抗摆希望沿摆速方向提供耗能加速度，两者可能在同一时刻方向相反。

在 SHADOW 之前，组合方式主要依靠：

```text
抗摆请求优先保留；
位置命令使用剩余总水平加速度预算；
总预算由 MC_HANG_TOT_A 限制。
```

这能保证安全包络，但不能保证最终命令在摆动能量意义上协调。结果可能是：

- 抗摆正在耗能；
- nominal 和 z3 同时或交替注能；
- 最终命令仍有明显正功率窗口；
- 抗摆达到自身 0.2 m/s² 限幅，但基础位置恢复仍占用大量控制权；
- 限幅改变各分量比例和相位，进一步增加可重复性问题。

原生 PID 没有额外的 `z3` 快速扰动补偿，也没有位置 LADRC/抗摆两个显式模块争夺同一包络。在当前参数下，它的命令更小、更平滑，因此反而较少激发摆频。

### 4.5 原因五：LADRC 的优势场景与当前测试场景并不完全匹配

LADRC 的优势通常出现在：

- 机体受到未知匹配扰动；
- 扰动能通过控制输入通道被补偿；
- 观测扰动的频带与被控对象期望频带可分离。

本研究的主要外力直接作用在吊载上。吊载通过绳张力、摆角和相位耦合到机体，属于附加柔性模态，并非简单的机体平移匹配扰动。

LESO 会把吊挂耦合的一部分看作“总扰动”并尝试补偿。若补偿相位恰好与摆速形成正功率，位置误差可能减小，但摆动能量上升。原生 PID 对该高频/柔性耦合不做强扰动重构，在当前工况下反而表现得更温和。

因此，不能仅靠增强 ESO 或提高带宽来超过 PID；必须明确区分机体低频位置扰动和吊摆模态。

### 4.6 原因六：命令功率不是负载总能量导数

当前诊断量：

\[
P_{cmd}=-L a_{cmd,h}^T\dot\theta_h
\]

描述机体水平加速度命令对摆动的预测贡献，但不包含：

- 直接施加在吊载上的 wrench 功率；
- 命令到实际加速度的延迟和姿态动态；
- 绳张力、三维运动和大角度非线性；
- 仿真阻尼、数值约束和测量滤波的功率项。

所以在 wrench 期间，即使机体控制贡献为负，吊载能量仍可能因外力持续输入而上升。历史上把“能量仍上升”直接等价为“抗摆符号错误”是不准确的。

命令功率适合用于控制协调和相对比较，不应在论文中称为完整真实能量导数。

### 4.7 原因七：历史垂向估计异常污染了水平/摆动比较

早期 airframe 配置为：

```text
EKF2_GPS_CTRL=1
EKF2_HGT_REF=0
```

`EKF2_GPS_CTRL=1` 只融合 GNSS 水平位置，不融合 GNSS 高度和三维速度；Z 轴主要依赖噪声较大的 baro 和 IMU 传播。

152852、154234 等组出现：

- Gazebo 真值正在下降；
- PX4 `vz` 却认为无人机正在上升；
- Z-PID 因错误速度反馈维持接近悬停推力；
- 真实高度误差显著大于 PX4 估计误差。

这会改变绳张力、摆动自然状态、姿态和水平控制余量，使不同控制器比较失去共同基础。

当前 SITL 诊断配置已改为：

```text
EKF2_GPS_CTRL=7
EKF2_HGT_REF=1
EKF2_BARO_CTRL=0
EKF2_RNG_CTRL=0
EKF2_GPS_P_NOISE=0.10
EKF2_GPS_V_NOISE=0.10
EKF2_GPS_DELAY=0
```

202007 外扰前最后 3 s 的真值高度 RMS 为 0.071 m，说明垂向链路已经满足当前可行性验证要求。该配置是 SITL 控制机理验证用配置，不代表实机最终估计器配置。

### 4.8 原因八：早期 wrench 清除和目标实体错误造成伪结果

已发现两类测试工具问题：

1. wrench 结束后只调用清除操作，Gazebo 可能保留上一次非零 wrench；
2. recorder 默认使用 `zd680_0::base_link`，而吊载实验应使用 `zd680_hang_0::hang_payload_link`。

200439 虽标记为 `valid=true`，但实际 metadata 指向 `zd680_0::base_link`，关节 CSV 为空，摆角和水平响应几乎没有被激发。该组不能验证 SHADOW。

修复后的正确配置为：

```text
model_name=zd680_hang_0
entity=zd680_hang_0::hang_payload_link
hang_joint_topic=/world/default/model/zd680_hang_0/joint_state
```

202007 中关节 CSV 完整、水平误差和摆角显著上升，说明扰动真正作用于吊载。

## 5. PID 当前表现更好的通俗解释

可以把吊挂系统理解为“无人机下面挂着一个有固定节奏的秋千”。

原生 PID 看到机体位置偏了，会按位置和速度误差逐渐拉回。它不知道“秋千扰动”是什么，因此不会额外生成一个快速的扰动补偿分量。在现有参数下，它的控制命令较小，虽然理论上不够聪明，但不容易踩中秋千节奏。

当前完整 LADRC 方案同时做三件事：

1. nominal 项拉回位置；
2. LESO 的 `z3` 项抵消估计扰动；
3. 能量抗摆项给吊摆耗能。

问题在于前两项有时正好在秋千加速方向发力，第三项则在反方向刹车。三个模块共享一个水平推力通道，结果不是“功能相加一定更好”，而可能是互相抵消、延迟后再大幅补偿。

频率约束把 LADRC 放慢后，短期看起来更温和，但位置误差积累后又会产生较大的恢复命令。因此历史完整方案出现了“参数看起来保守，实际恢复阶段命令却更大”的现象。

要超过 PID，不是简单把 LADRC 再调快或再调慢，而是要阻止位置恢复命令在高摆动能量阶段持续向吊摆注入正功率，同时保留低频位置恢复能力。


### 6.2 可以得出的结论

1. SHADOW 修正主要出现在较高能量、较高摆速和正候选功率阶段；
2. 修正方向能够降低预测正功率积分；
3. 当前修正峰值仅 0.03 m/s²，相对总包络 0.8 m/s² 很小；
4. SHADOW 不会改变闭环，当前飞行安全性和基线行为保持不变；
5. 数据满足分阶段任务书中“修正量主要出现在正功率、较高能量阶段，且幅值合理”的 ACTIVE 前置条件。

### 6.3 不能得出的结论

1. 不能说 SHADOW 已降低实际摆角，因为它没有执行；
2. 不能说完整方案已优于 PID，因为当前没有在同一估计器、同一初态门槛下重新飞 PID；
3. 不能说 6.6% 预测功率削减一定等价于 6.6% 能量或摆角改善；
4. 不能说 Z3 陷波一定必要，因为 nominal 是重要正功率来源；
5. 不能把命令级预测功率当成真实总能量导数。

## 8. 已解决、部分解决和未解决的问题

### 8.1 已解决

- 一阶外环 LADRC 与二阶 LADRC 的选择冲突；
- 起飞大高度阶跃后持续越过目标的二阶 LADRC 初始化问题；
- X/Y 二阶 LADRC＋Z 原生 PID 的结构隔离；
- 吊挂关节状态接入和 yaw 航向变换的基本方向验证；
- wrench 清除与残留有效性标记；
- nominal/raw/selected 控制量分解；
- SHADOW 预测功率和候选修正日志；
- SITL 高度和垂速融合的主要错误；
- 正确吊载实体和关节话题的实验命令。

### 8.2 部分解决

- 高度控制：202007 已满足可行性门槛，但 recorder 尚未自动使用 Gazebo 真值做 pre-wrench 判定；
- 初态一致性：命令行门槛已更严格，但真正 wrench 前的二次门槛仍需自动化；
- 控制包络：当前有效组无总饱和，但历史组曾长期触顶；
- 能量协调：SHADOW 方向已验证，实际闭环效果未知。

### 8.3 未解决

- ACTIVE 能量监督能否实际缩短恢复时间并保持位置误差；
- nominal 项正功率是否需要额外门控或动态位置/抗摆权重；
- 当前 6%～7% 的预测削减是否足以产生可测量的摆角改善；
- 最终公平 PID 对比尚未在统一 EKF 和统一 pre-wrench 门槛下完成；
- 多绳长、多质量和轨迹实验尚未开始；
- 实机估计器、关节传感器与 Gazebo truth 的迁移边界尚未验证。

## 9. 第二阶段总体判断

当前可以作出以下工程判断：

> 二阶 LADRC-X/Y＋PID-Z＋能量抗摆＋频率约束的基础链路是可运行的，能量抗摆本身具有耗能方向，完整方案历史上不如 PID 的主要原因不是单一坐标错误或单一参数，而是位置 nominal、LESO 扰动补偿和抗摆共享控制通道但缺少能量协调，加上过于保守的频率调度、恢复期大命令以及早期实验条件不一致。

同时可以作出以下阶段判断：

> 202007 已经使能量协调 SHADOW 达到进入低增益、严格门控 ACTIVE 评估的前置数据条件；但在 ACTIVE 实际飞行前，不能宣称该完整方案优于 PID。

## 10. 下一阶段边界

若进入下一阶段，应只实现最小化的能量监督 ACTIVE：

```text
MC_HANG_PAS_MD=2；
复用已经验证的 SHADOW 修正；
初始有效修正峰值保持约 0.03 m/s²；
保留能量、摆速、正功率、dwell、限幅和 slew 门控；
无效/超时/低能量时平滑回零；
继续记录 candidate、projected、final、thrust power；
保持主动陷波、Z3 选择器和 LESO 执行模型关闭。
```

ACTIVE 第一组只需要与 202007 SHADOW 基准比较，不需要重飞 SHADOW。至少检查：

```text
实际最终正功率积分是否下降；
摆角峰值、能量积分或恢复时间是否改善；
水平位置 RMS 恶化是否小于 10%～15%；
高度真值 RMS 是否小于 0.10 m；
是否出现高频抖动、总加速度饱和或 safety abort。
```

在 ACTIVE 结果出现前，不实施主动 Z3 陷波，不实施 LESO 执行模型，不把测量加速度直接输入 LESO。

## 13. 最终摘要

历史完整方案不如 PID，并非证明 LADRC 或能量抗摆理论无效，而是说明当前组合方式尚未解决柔性吊摆模态与刚体位置恢复之间的频带和能量冲突。

PID 在当前工况下更好，主要因为其命令较小、没有独立 `z3` 补偿快速追逐吊挂耦合、恢复过程较少触及总加速度包络。当前 LADRC 完整方案虽然加入了频率约束和能量抗摆，但 nominal 与 disturbance 补偿仍可能注能，抗摆只能在同一控制通道内与它们竞争；过度保守的带宽又造成误差积累和恢复期大命令。

与此同时，早期实验还受到初始摆角、垂向估计、wrench 残留和错误实体等问题影响，因此历史差距不能直接作为最终论文公平比较。

202007 已经建立新的有效数据基准：高度合格、吊载外扰有效、抗摆耗能、SHADOW 门控正确，预测正功率积分下降约 6%～7%。这证明研究方向仍具有可行性，但真正能否超过 PID，必须由下一阶段的受限 ACTIVE 能量协调和随后统一条件下的 PID 对比回答。
