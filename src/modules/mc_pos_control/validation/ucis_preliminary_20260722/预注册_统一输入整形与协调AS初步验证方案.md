# ZD680统一输入整形—协调AS方法初步验证预注册

冻结时间：2026-07-22，代码实现和正式SITL出数前。

## 1. 固定研究主线

本轮不更换PID、AS或频率估计研究方向，只验证同一结构的三个层级：

1. A：PX4 PID＋原能量型AS基线；
2. B：A＋标称频率ZVD输入整形；
3. C：B＋频率可信度安全退化＋位置/加速度/jerk协调AS权限。

HESO/RLS只提供频率及可信度，不允许直接加速度补偿，也不再把AS增益放大到1以上。当前飞行交叉检查未达到频率闭环门槛时，C必须平滑退回标称频率；这属于完整方法的安全工作点，不得用低可信估计强行自适应。

## 2. 输入整形冻结实现

- 使用阻尼比0.10的三脉冲ZVD；
- 脉冲间隔由`pi/(omega*sqrt(1-zeta^2))`给出；
- 为保持每段移动仍为6 s，将未整形S曲线的执行时间缩短`2T`，再因果卷积回6 s；
- 轨迹位移、单段总时长和末端位置不变；
- 记录时间压缩带来的峰值速度/加速度代价；
- C在可信度不足时使用标称频率，与B的整形轨迹一致，性能差异只来自协调AS。

## 3. 协调AS冻结实现

- 原AS候选保持不变，倍率范围改为0到1，绝不增强；
- 权限由位置误差门、剩余水平加速度门和基础控制jerk门共同决定；
- 权限以1/s速率平滑；
- C模式中基础PID优先使用总加速度预算，AS只使用剩余权限；
- AS自身功率仍要求非正，HESO/RLS直接补偿严格为0。

## 4. 数据、顺序与预算

- 绳长0.6 m，载荷0.5 kg；
- 四方向2 m/6 s，段间保持5 s，末段保持10 s；
- 初始门使用已冻结的0.25 deg、0.020 rad/s、0.08 m条件；
- 正式顺序固定：`A1 -> B1 -> C1 -> C2 -> B2 -> A2`；
- 最多6次正式飞行，不因结果追加；短程READY不计入性能数据。

## 5. 初步可行性判据

### B对A：输入整形作用

- 两对摆角RMS和能量积分均下降；
- 均值摆角RMS不高于-5%；
- 均值能量积分不高于-8%；
- 原任务时间参考XY RMS不高于+10%；
- jerk P95不高于+10%。

### C对B：协调器不能破坏整形收益

- C摆角RMS与能量相对B均值不劣于+3%；
- C原任务时间参考XY RMS相对B下降或不高于+2%；
- C jerk P95相对B下降或不高于+2%；
- AS权限在0到1内且实际变化；
- HESO/RLS直接补偿为0、AS正功积分为0。

### C对A：完整方法初步成立

- 两对摆角RMS和能量均下降；
- 均值摆角RMS不高于-5%，能量不高于-8%；
- XY RMS不高于+10%，jerk P95不高于+7%；
- 6次均有效、无failsafe。

## 6. 决策

- B失败：输入整形的等时实现需要在同一主线内重构，不更换PID/AS/HESO框架；
- B通过、C失败：保留输入整形，修改协调权限公式；
- B和C均通过：进入HESO/RLS可信频率在线接入和多绳长泛化；
- 低可信频率回退标称值不算估计器通过，必须单独报告。
