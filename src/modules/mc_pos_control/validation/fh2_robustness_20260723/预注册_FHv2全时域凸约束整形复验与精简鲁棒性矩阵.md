# ZD680 FHv2 全时域凸约束频率不确定性轨迹整形复验与精简鲁棒性矩阵预注册

冻结时间：2026-07-23，任何正式 SITL 出数前。

## 1. 路线与范围（冻结）

- 主线不变：PX4 PID 位置环 + 能量型 AS + 模式6统一协调器 + 离线频率不确定性有限时域整形。
- **在线频率支路明确降级**：HESO/RLS 仅作影子诊断记录，整形频率只使用离线区间 `[0.90, 1.20]`（相对标称绳长）。论文表述为"离线区间鲁棒整形 + 在线安全退化"，不宣称在线频率自适应闭环。
- FHv2 替代 FHv1：全时域摆角/峰值/jerk/非零初态凸约束 QP（order-16 端点平坦基 `u^(k+3)(1-u)^(18-k)`），求解器 OSQP+约束生成，稠密独立审计。

## 2. 冻结设计参数

统一规则：频率比区间 `[0.90, 1.20]`，设计网格 `0.90:0.05:1.20`；角点初态 `±0.5°/±0.02 rad/s`（取自 FHv1 失败飞行实测段初值）；jerk 设计界 1.59 m/s³（审计网格 ≤1.61）；速度 [-0.01, 0.54] m/s；加速度 ≤0.65 m/s²；位置越界 ≤0.005 m；系数 ≤0.20 m；指令偏差峰值 ≤0.15 m；终端模态凸盒 |Re|,|Im| ≤0.80°；目标权重 跟踪20/终端5/加速度0.02/正则1e-4。

摆角界按绳长冻结（同规则、可行性自适应，飞行前冻结不得再改）：

| 绳长 | 零初态摆角界 | 角点初态摆角界 |
|---|---:|---:|
| 0.5 m | 2.7° | 3.7° |
| 0.6 m | 2.7° | 3.7° |
| 0.8 m | 3.0° | 4.0° |

## 3. 离线门（全部已于 2026-07-23 通过，证据 `fh2_design.json`）

- 指令偏差 RMS ≤ 0.095 m（**修订**：FHv1 的 0.075 门与摆角/jerk 安全约束联合不可行；可行性扫描证明 0.089~0.093 为 Pareto 下界。依据：旧 FUCI 离线 0.098→实飞 0.064、FHv1 离线 0.065/0.072→实飞 0.040/0.046 的映射，离线 0.095 对应实飞约 0.06，飞行 XY 门 0.12 m 仍有充足余量。真正的任务保真保护是飞行 XY 门）；
- 峰值速度 ≤ 0.55 m/s；峰值加速度 ≤ 0.65 m/s²；峰值 jerk ≤ 1.61 m/s³；
- 稠密网格最坏终端模态 ≤ 1.15°；
- 稠密网格最坏瞬态摆角：零初态 ≤ 界+0.05°，角点初态 ≤ 界+0.05°；
- 位置越界 ≤ 0.005 m；速度不反转（≥ -0.02 m/s）；求解器残差 ≤ 5e-3。

## 4. 反事实筛选（已于 2026-07-23 通过，证据 `fh2_counterfactual.json`）

方法修订声明：原计划"实际加速度逐段回放"因 live/joint 时钟偏差与速度微分噪声不可用（平静段幻象摆角 4°），改为**参考加速度全任务链式回放**：先用同一机构对 FHv1 失败轨迹做验证（摆动主导轴 east/west 峰值误差 +0.32/+0.50°@0.6 m、+0.69/+0.98°@0.8 m，模型保守），再对 FHv2 预测。发现真实系统 X/Y 轴不对称（X 轴有额外阻尼，模型对 X 保守、对 Y 校准）。

门：FHv2 链式预测最坏段峰值 < 3.5°（实测 2.635°@0.6 m、2.473°@0.8 m）且参考 jerk < 1.6 m/s³（实测 1.599）。**通过**。

## 5. 正式数据与顺序（精简版，用户批准）

1. 门槛复验：`FH2_06`（0.6 m）、`FH2_08`（0.8 m）各 1 次，顺序固定，无效不补跑；
2. 精简鲁棒性矩阵（方法 FHv2）：`L05`×3、`L06`×2、`L08`×2、`P75`（0.6 m/0.75 kg）×3、`MM070`（物理 0.70 m/标称 0.6 m 频率失配）×3；
3. 基线对照：`STD_L08_PID_AS`（PID+AS 不整形）×3；0.6 m 基线复用 2026-07-22 快速封版 n=5 数据；
4. 总预算 16 次，约 65 分钟；矩阵点内顺序固定，单次无效则该点记 n<3 并在报告中明示，不追加超过 2 次补跑。

## 6. 飞行门（每次运行）

- 严格有效、failsafe 为 0、模式6选择率 100%；
- 摆角 RMS ≤ 1.0°、峰值 ≤ 4.0°；
- 任务 XY RMS ≤ 0.12 m；
- 闭环 jerk P95 ≤ 2.0 m/s³；
- HESO/RLS 直接补偿为 0、AS 正功积分为 0、实现 AS 比例 ≤ 1。

门槛判定：`FH2_06` 与 `FH2_08` 全部门通过 → 双绳长初步鲁棒性 PASS，进入矩阵。
矩阵判定：每点均值过门且单次过门率 ≥ 2/3 → 该点 PASS；报告均值±SD，不做统计显著性宣称（n≤3 仅作工程筛查证据）。

## 7. 与旧方法的关系（报告用对照，不设门）

- FH2_06 对比旧 FUCI1（2026-07-22）与 FH06：摆角 RMS/峰值/能量/XY/指令偏差/jerk 变化百分比；
- 矩阵各点对比同点基线（L08 新测、L06 复用）。
