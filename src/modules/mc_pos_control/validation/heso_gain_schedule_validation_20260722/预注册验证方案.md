# PID+AS+HESO 有效频率/可信度增益调度预注册验证方案

冻结时间：2026-07-22（正式闭环运行前）

## 1. 结构假设

主控制器保持 PX4 PID，基础抗摆保持现有能量阻尼 AS。候选方案不叠加 HESO 水平加速度；HESO 仅通过 7 个候选频率（标称频率的 0.70～1.30 倍）估计有效摆频，并由频带对比度、估计稳定度和摆动激励形成可信度。

AS 调度倍率为：

```text
K_AS = K_AS,base * [1 + 0.40 * G_conf * G_energy * G_position * G_frequency]
```

其中 `G_frequency` 限于 0.9～1.1，最终倍率限于 1.0～1.4，并以 0.30 /s 变化。可信度不足、能量不足、位置误差大、测量失效或模块关闭时，倍率平滑/立即回到 1；`compensation_applied_ned` 必须严格为 0。

## 2. 冻结参数

| 参数 | 值 |
|---|---:|
| 主控制器 | PX4 PID |
| AS 模式 | 能量阻尼 |
| `MC_HANG_ZETA` | 0.10 |
| `MC_HANG_K_RATE` | 0.60（保留但能量模式不用该项） |
| `MC_HANG_ACC_LIM` | 0.20 m/s² |
| `MC_HANG_ACC_SLW` | 2.0 m/s³ |
| `MC_HANG_FSO_MD` | 3（HESO gain schedule） |
| `MC_HANG_FSO_BW` | 0.30 Hz |
| `MC_HANG_FSO_K` | 0.40（最大相对增益增量） |
| `MC_HANG_FSO_SLW` | 0.30 /s（调度倍率变化率） |
| `MC_HANG_FSO_E` | 0.003 J/kg；0.009 J/kg 达到全能量门控 |
| `MC_HANG_FSO_R` | 0.03 rad/s |
| `MC_HANG_FSO_T` | 2.0 s |
| `MC_HANG_FSO_CF` | 0.20；0.45 达到全可信门控 |
| `MC_HANG_FSO_POS` | 1 |
| `MC_HANG_FSO_PE` | 0.05 m；0.10 m 完全退出调度 |
| 总水平加速度限制 | 0.80 m/s² |
| 载荷 | 0.5 kg |
| 轨迹 | 四方向 2 m、6 s S 曲线，段间保持 |

除实际绳长与 `MC_HANG_LEN` 外，L=0.6 m 与 L=0.8 m 使用同一二进制、同一参数。

## 3. 运行顺序与预算

- 就绪检查：`STD_L06_PID_AS_HGS_READY`，不计入正式结果。
- 第一关：L=0.6 m，固定 `A1 -> B1 -> A2 -> B2`。
- 第二关：第一关通过后，L=0.8 m，固定 `A1 -> B1 -> A2 -> B2`。
- A 为 `PID+AS`；B 为 `PID+AS+HESO 调度`。
- 正式预算最多 8 次；不因结果不好追加，不在正式运行之间改参数或代码。

## 4. 性能闸门

百分比均为 `(B-A)/A*100%`。

| 条件 | L=0.6 m | L=0.8 m |
|---|---:|---:|
| 四次均有效 | 必须 | 必须 |
| 两对摆角 RMS、能量积分逐对下降 | 必须 | 必须 |
| 均值摆角 RMS | <= -2% | <= -2% |
| 均值能量积分 | <= -3% | <= -3% |
| 峰值摆角 | <= +5% | <= +5% |
| XY RMS | <= +5% | <= +5% |
| jerk P95 均值 | <= +7% | <= +7% |
| 任一配对 jerk P95 | <= +12% | <= +12% |

第一关失败即停止 L=0.8 m。两关通过只定义为“结构初步可行”，不能替代论文级多载荷、多扰动、实机和统计重复。

## 5. 机制闸门

- B 组 HESO 调度模式必须为 3，A 组为 0。
- B 组 HESO 直接补偿 RMS、P95、峰值均为 0（浮点容差 `1e-7 m/s²`）。
- B 组增益倍率必须在 `[1.0, 1.4]`，且有非零激活时间。
- 有效频率必须始终位于标称频率的 `[0.70, 1.30]`。
- 可信度、能量、位置门控均存在有限且非恒定的记录；位置误差大时调度倍率不能继续上升。
- AS 控制功率应保持非正（数值容差 `1e-5`）；本方案的理论安全性来自只增强原耗散项且不改变原 AS 限幅/斜率限制。

## 6. 决策

- 两关均通过：`KEEP_HESO_AS_GAIN_SCHEDULING`。
- L06 通过而 L08 失败：`KEEP_LOCAL_ONLY_NEEDS_GENERALIZATION`。
- L06 性能失败：`STOP_CURRENT_HGS_PARAMETERS`。
- 机制闸门失败：`STOP_HGS_MECHANISM_INVALID`。
- 平台在预算内无法形成完整配对：`STOP_PLATFORM_INVALID`。
