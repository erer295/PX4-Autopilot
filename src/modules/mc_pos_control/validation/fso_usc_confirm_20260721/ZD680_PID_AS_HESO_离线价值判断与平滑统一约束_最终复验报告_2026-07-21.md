# ZD680：保留 PID+AS 的 HESO 离线价值判断与平滑统一约束最终复验

日期：2026-07-21

## 1. 范围和冻结规则

本轮严格按限定只进行一次 HESO 直接补偿路线迭代：

1. 使用上一轮三次确认 ULog 做一次离线信号价值判断；
2. 只实现一个“连续门控＋平滑统一约束”版本；
3. 单次预检后不再修改算法、增益或约束参数；
4. 用全新目录执行 `PID+AS / 候选 / PID+AS / 候选 / PID+AS / 候选` 三对交错复验；
5. 预检数据不进入最终均值。

主控制始终保留 PX4 位置 PID 和原 AS。HESO 只作为附加水平补偿，默认模式仍为 `OFF`。

## 2. 最终结论

这次改版取得了有意义但不完整的进步：

- 6 次最终复验全部严格有效，基线和候选均为 3/3；
- 候选的摆角 RMS 三对均下降，平均下降 `4.40%`；
- 摆动能量积分三对均下降，平均下降 `7.40%`；
- 末 5 s 摆角 RMS 平均下降 `7.89%`；
- XY RMS 仅增加 `0.41%`，基本消除了旧功率约束版本 `+15.24%` 的位置代价；
- HESO 实际补偿 jerk P95 被限制到 `0.30 m/s³`，峰值由旧硬投影的 `8.60–11.16` 降到 `0.60–0.90 m/s³`。

但仍有三项没有通过预先设定的终线：

- 摆角峰值平均增加 `1.24%`，没有做到三个主要摆动指标均不恶化；
- 总控制 jerk P95 增加 `5.09%`，比 5% 门限高 `0.09` 个百分点；
- 移动半空间和严格斜率圆盘约 `12.71%` 时间无共同可行解，降级路径累计产生 `0.01454 J/kg` 正摆动功，失去了旧版本“补偿正功为数值零”的严格性质。

因此最终判断是：**平滑统一约束明显优于上一轮硬联合约束，证明 HESO 信号对摆动 RMS 和能量有一定价值；但 HESO 直接加速度补偿仍不满足最终论文通过线。本轮到此停止，不继续追调这条直接补偿路线。PID+AS 保留为工程主线和默认方案。**

## 3. 一次离线信号价值判断

离线数据来自上一轮三个 `K=0.20` 联合约束确认样本，共 6868 个 HESO 激活采样点。

### 3.1 原始信号是否包含消摆信息

| 样本 | 原始负功采样比例 | 原始正功采样比例 | 原始正功积分 (J/kg) | 原始负功积分 (J/kg) |
|---|---:|---:|---:|---:|
| C1 | 53.92% | 46.08% | 0.04855 | -0.05444 |
| C2 | 54.01% | 45.99% | 0.04890 | -0.05608 |
| C3 | 55.33% | 44.67% | 0.04045 | -0.05181 |
| 合计 | 约54.4% | 约45.6% | 0.13790 | -0.16232 |

原始信号合计净功约为 `-0.02442 J/kg`，说明它不是纯噪声，确实含有弱的净消摆成分。但正、负功接近，接近一半时间相位方向不适合直接补偿。

### 3.2 旧约束后还剩多少信号

旧硬联合约束仅保留原始补偿 RMS 的 `38.0%–45.7%`，负功积分从 `-0.16232` 降到 `-0.08646 J/kg`，只保留约 `53.3%` 的原始负功能力。同时旧版本产生 `8.60–11.16 m/s³` 的补偿 jerk 峰值。

离线价值判断因此为：

> HESO信号具有有限而真实的消摆价值，值得做一次平滑统一约束复验；但信号相位可靠性不足，不值得继续进行多轮直接补偿追参。

## 4. 唯一一次算法修改

### 4.1 连续门控

旧版本按稳定时间、能量和摆速做布尔开关。本轮改成三次平滑函数连续权重：

```text
gate_scale = settled_scale * energy_scale * rate_scale
a_raw = -K * gate_scale * d_lead
```

稳定时间在原门限后 0.5 s 内淡入；能量和摆速在各自门限的 `0.5–1.5` 倍范围内连续变化。

### 4.2 连续位置约束

`MC_HANG_FSO_PE=0.05 m` 不再是硬开关。位置保护从 `0.025 m` 开始连续收紧，在 `0.05 m` 为半权重，在 `0.075 m` 达到全权重。

位置半空间由完全放松连续移动到：

```text
a_comp^T * e_position_hat >= 0
```

### 4.3 单次统一约束

每个控制周期用固定 32 次 Dykstra 投影，在一次求解中同时处理：

- 补偿幅值圆盘；
- 连续收紧的摆动功率半空间；
- 连续收紧的位置恢复半空间；
- 以上一时刻补偿为中心的实际斜率圆盘。

删除旧版本：

```text
约束投影 → 斜率限制 → 再次硬投影
```

若移动半空间与斜率圆盘瞬时无交集，算法保持斜率硬限制并平滑衰减到零，同时把 `unified_constraint_feasible=false` 写入日志。这样不再用隐藏跳变强行满足功率或位置约束。

### 4.4 新日志

`debug_array ID 687` 在原索引后增加：

- 连续门控比例；
- 功率约束权重；
- 位置约束权重；
- 两个连续半空间下界；
- 统一约束可行标志。

旧索引保持不变。

## 7. 最终机理审计

三次候选共有 8905 个激活采样点。

| 项目 | 最终结果 |
|---|---:|
| 原始补偿负功采样比例 | 50.6%–51.5% |
| 约束后/原始补偿 RMS | 53.0%–53.4% |
| 统一约束不可行率 | 11.65% / 13.48% / 13.04%，合计12.71% |
| 补偿 jerk P95 | 三次均约0.30 m/s³ |
| 补偿 jerk 峰值 | 0.90 / 0.60 / 0.60 m/s³ |
| 约束后正功积分 | 0.00468 / 0.00434 / 0.00552 J/kg |
| 约束后负功积分 | -0.03692 / -0.04044 / -0.04105 J/kg |
| 合计正功 / 负功 | 0.01454 / -0.11842 J/kg |

总体净补偿功为 `-0.10388 J/kg`，仍是明显耗散的；但全权重功率约束下仍有 `553/7813=7.08%` 的采样因不可行降级而出现大于 `1e-6` 的正功。因此它是“总体净耗散”，不是“每个时刻严格非正功”。

位置约束在全权重区间的可行性更差：`207/377` 个采样出现负位置对齐，主要原因是上一时刻补偿、当前功率半空间、位置半空间和很小的斜率圆盘没有共同交集。平滑结构避免了跳变，却不能凭空消除数学上的瞬时冲突。

## 9. 对 HESO 直接补偿路线的最终判断

### 可以确认的内容

- HESO 原始信号含有可重复的弱消摆成分；
- 平滑统一约束能够把该成分转化为一致的 RMS 和能量改善；
- PID+AS 主路径未被替换，候选在 3 次严格有效试验中保持稳定；
- 硬联合投影造成的补偿 jerk 峰值已基本解决。

### 仍无法确认的内容

- 不能证明摆角峰值改善；
- 不能证明每个时刻的补偿功率严格非正；
- 不能同时严格满足快速移动的功率、位置和斜率约束；
- 只有单一绳长、负载和仿真环境；n=3 仍不足以支撑论文显著性结论。

### 路线决策

按本轮“一次判断、一次改版、一次复验”的约定，**不再继续调 HESO 直接补偿的 K、相位、限幅或约束权重。** 当前实现保留为研究消融和 SHADOW 诊断路径，默认不启用 ACTIVE。

后续主线建议：

1. 生产和实机控制继续使用 `PID+AS`；
2. HESO仅在 SHADOW 中输出频率、幅值和相位置信度，不直接叠加水平加速度；
3. 若继续做论文创新，优先让 HESO用于 AS 增益调度、自然频率辨识或输入整形，而不是直接补偿；
4. 新主线仍需两种以上绳长、三种负载、扰动/噪声/时延、每格至少5次严格有效重复，以及 HIL 或小载荷实飞。

## 10. 北大核心投稿判断

当前版本比上一轮更接近可写状态，但仍不建议仅凭本轮直接投稿。原因是峰值未改善、jerk略超线、严格瞬时约束有降级，并且样本和工况不足。

可以把本轮作为论文中的完整消融：它能够证明硬位置投影为何失败、平滑统一约束如何改善折中，以及 HESO 信号具有有限而非绝对的控制价值。真正的论文最终方法建议转为：

```text
PID+AS主控制
+ HESO频率/相位置信度估计
+ AS参数调度或参考输入整形
```

这样保留本轮已经验证的频率信息价值，同时避免相位不可靠的 HESO 向量与 PID、AS、位置恢复方向直接争夺控制量。
