# HESO 辅助 PID+AS：阶段1频率识别与阶段2因果消融预注册方案

冻结时间：2026-07-22（阶段1脚本正式出数、阶段2闭环飞行前）

## 1. 要回答的问题

阶段1只回答“哪个频率估计结构在已知频率信号和现有飞行数据上更可信”，不改变闭环控制。

阶段2把估计问题和调度问题拆开：

- A：PID+AS 基线；
- B：PID+AS＋仿真真值频率调度，检验当前调度器的性能上限；
- C：PID+AS＋阶段1胜出估计器影子运行，倍率严格为1；
- D：PID+AS＋阶段1胜出估计器闭环调度。

若 B 不能改善，则当前 AS 增益调度本身价值不足；若 B 改善而 D 不改善，则主要问题是估计器/可信度；若 B、D 都改善，完整路线才初步成立。

## 2. 阶段1数据与算法

### 2.1 数据

1. 2026-07-22 L=0.6 m 四条正式 ULog；
2. 频率比 `0.75/0.85/0.95/1.00/1.05/1.15/1.25` 的二维合成吊挂信号；
3. 每个频率包含低/中两档测量噪声，以及基础加速度激励、慢变外扰和不同阻尼；
4. 低能量无充分激励反例。

### 2.2 比较结构

- `legacy_heso_bank`：复现当前7候选HESO及校正后创新评分；
- `predictive_bank`：用校正前一步物理预测残差评分，不允许候选扰动状态即时擦除频率失配；
- `filtered_rls`：使用角速度增量的窗口积分回归估计 `omega^2`，投影到0.7～1.3倍物理范围。

### 2.3 阶段1门槛

胜出结构必须首先满足安全/有限性，并按以下顺序选择：

1. 合成充分激励样本的中位绝对误差最小；
2. 中位误差目标 `<=3%`，P95目标 `<=5%`；
3. 现有飞行数据估计中位数与独立FFT主峰差异目标 `<=5%`；
4. 低能量反例不得产生可用于闭环的高可信输出；
5. 若没有结构达到目标，阶段2只执行 A/B 真值频率因果试验，C/D保留为影子诊断，不宣称估计器已通过。

参数只允许用确定性的合成开发集固定一次；正式汇总不得针对单条飞行结果调参。

## 3. 阶段2冻结结构

- 绳长0.6 m，载荷0.5 kg；
- 四方向2 m/6 s S曲线，段间保持5 s，末段保持10 s；
- PID、基础AS及0.20 m/s^2限幅保持不变；
- 调度最大相对增量先保持0.40，倍率范围1～1.4，变化率0.30/s；
- B的真值频率比固定为1.0，可信度固定为1，但仍保留能量门、位置门、倍率限幅和斜率限制；
- C的估计器持续输出诊断，AS倍率严格为1；
- D使用与C完全相同估计器和可信度，仅打开调度作用。

## 4. 阶段2顺序和预算

正式顺序固定为：

```text
A1 -> B1 -> C1 -> D1 -> D2 -> C2 -> B2 -> A2
```

最多8次，不因结果不好追加。所有模式使用同一二进制。初始条件绝对门槛收紧为摆角RMS不超过0.20度、角速度RMS不超过0.015 rad/s、XY误差不超过0.08 m，并记录配对差异；配对差异过大只作为证据限制，不事后删数。

## 5. 判据

### 5.1 运行和机理

- 8次均有效；
- B/D直接HESO加速度补偿严格为0；
- B真值频率比为1，C/D估计有限且在0.7～1.3；
- B/D增益倍率在1～1.4且有激活，C倍率严格为1；
- AS功率非正。

### 5.2 因果可行性门槛

B对A、D对A分别评价：

- 两个配对摆角RMS与能量积分均逐对下降；
- 均值摆角RMS `<=-2%`；
- 均值能量积分 `<=-3%`；
- XY RMS `<=+5%`；
- jerk P95均值 `<=+7%`，任一配对 `<=+12%`。

另外记录论文级目标：摆角RMS `<=-5%`、能量 `<=-8%`、XY与jerk `<=+5%`。可行性通过不等于达到论文级目标。

## 6. 决策

- B失败：`STOP_CURRENT_AS_GAIN_SCHEDULER`；优先转向HESO辅助输入整形或重构协调分配。
- B通过、D失败：`ESTIMATOR_CONFIDENCE_IS_PRIMARY_BLOCKER`。
- B和D都通过：`KEEP_HESO_AS_GAIN_SCHEDULING_FOR_GENERALIZATION`。
- 阶段1无合格估计器：明确标记，不以闭环偶然改善覆盖估计器失败。
