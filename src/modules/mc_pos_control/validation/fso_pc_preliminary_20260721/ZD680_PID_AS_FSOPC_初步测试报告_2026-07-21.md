# ZD680：PX4 PID + AS + 频率选择性扰动观测 + 补偿功率约束初步报告

日期：2026-07-21  
性质：方案可行性筛选，不是论文正式统计  
对象：0.6 m 绳长、0.5 kg 负载、固定模拟电池、GPS-only EKF、四次 2 m S 曲线平移

## 1. 先给结论

**这条结构可以继续作为候选主线，但当前版本不能直接冻结为论文主方案。**

结论分成两层：

1. **工程可行性成立。** 新模块能以插件方式接在现有 PX4 `PID + AS` 后面；默认关闭时不改变原基线；频率选择、幅值/变化率限制、能量门控和补偿功率投影均能运行；编译、单元测试和 SITL 路线均通过。补偿项的正功积分在两次有效候选试验中约为 `3.4e-11`、`3.9e-11 J/kg`，可以视为数值零，说明“补偿项不向摆动注能”的样本级约束确实生效。
2. **独立性能增益尚未成立。** 候选方案相对本轮一条有效基线，位置 RMS、摆角 RMS 和能量积分分别小幅下降约 4.2%、1.5% 和 2.9%，但峰值摆角上升约 2.2%。更重要的是，候选均值没有超过 2026-07-15 已完成的三次固定电池 `PID + AS` 强基线。当前补偿 RMS 只有约 `0.0037 m/s²`，最大约 `0.0151 m/s²`，远小于设置的 `0.08 m/s²` 上限，说明目前不是安全限幅压住了性能，而是观测残差、相位/增益或激活门控使有效补偿过弱。

所以建议是：**保留 `PID + AS` 作为不动的强基线，保留 FSO-PC 作为增量模块；下一步集中修改观测残差、延迟相位和频率模型，而不是再次更换整个位置外环。**

## 2. 当前实现的结构

本轮实现的是：

```text
PX4 位置 PID
      + 直接 AS 阻尼项
      + 频率选择性扰动补偿 FSO
            ↓ 幅值限制、变化率限制、能量/摆速门控
            ↓ 补偿功率半空间投影 P_comp <= 0
      → 总水平加速度包络 → 姿态/推力控制
```

频率中心由绳长在线计算：

```text
f_n = sqrt(g/L) / (2*pi)
```

当 `L = 0.6 m` 时，`f_n = 0.643435 Hz`。观测器以

```text
r_a = a_measured - a_command(previous cycle)
```

为加速度残差，通过同步解调和两级 I/Q 低通只提取 `f_n` 附近的周期分量。候选补偿为观测值的反向比例项。

小角度摆动单位质量能量满足：

```text
E = 0.5*L^2*|theta_dot|^2 + 0.5*g*L*|theta|^2
dE/dt attributable to compensation = P_comp
P_comp = -L * a_comp_heading · theta_dot
```

若原始补偿导致 `P_comp > 0`，就把补偿投影到 `P_comp <= 0` 的半空间。该约束仅作用于新增补偿，不篡改原有位置 PID 和直接 AS 的职责。

当前冻结的初测参数为：

| 参数 | 值 | 含义 |
|---|---:|---|
| `MC_HANG_FSO_BW` | 0.15 Hz | 同步观测低通带宽 |
| `MC_HANG_FSO_K` | 0.20 | 补偿增益 |
| `MC_HANG_FSO_LIM` | 0.08 m/s² | 补偿幅值上限 |
| `MC_HANG_FSO_SLW` | 0.30 m/s³ | 补偿变化率上限 |
| `MC_HANG_FSO_E` | 0.003 J/kg | 摆动能量激活阈值 |
| `MC_HANG_FSO_R` | 0.03 rad/s | 摆速激活阈值 |
| `MC_HANG_FSO_T` | 2.0 s | 观测器稳定等待时间 |

`MC_HANG_FSO_EN` 默认值为 0；因此编译这套代码不会自动改变现有飞行基线。原有全命令 PAS 在本轮路线中保持关闭，避免把两种功率机制混在一次消融里。

## 3. 为什么这个方向在文献上合理，但不能只靠名称当创新

已有工作说明这条技术路线有理论依据：

- Shi、Wu 和 Chou 的吊挂四旋翼 HESO 工作指出，吊物扰动具有周期结构，传统主要面向慢变扰动的 ESO 对这类信号存在周期估计误差；其方法把谐波扰动模型嵌入观测器，并给出 Lyapunov 分析、仿真和实时实验：[Harmonic Extended State Observer Based Anti-Swing Attitude Control for Quadrotor with Slung Load](https://doi.org/10.3390/electronics7060083)。
- Gadelovits 等针对已知基频的周期扰动，采用匹配选定频带的链式 UDE 滤波器，在控制带宽受限时兼顾扰动抑制与稳定裕度：[Design of a UDE Frequency Selective Filter to Reject Periodical Disturbances](https://doi.org/10.1016/j.ifacol.2017.08.1059)。
- Guerrero-Sánchez 等利用系统平移动力学的能量与无源性性质设计吊挂减摆控制，并给出 Lyapunov 稳定性证明：[Energy-Based Control and LMI-Based Control for a Quadrotor Transporting a Payload](https://doi.org/10.3390/math7111090)。
- 2025 年的双 TVUDE 工作已经把时变扰动估计同时放入轨迹与减摆回路，并用对比仿真和实验验证：[Trajectory tracking and load anti-swing control ... dual TVUDE-based approach](https://doi.org/10.1016/j.conengprac.2025.106518)。

因此：

- “对吊挂周期扰动做频率选择性估计”本身不是新点；
- “利用能量/无源性做减摆”本身也不是新点；
- 可形成论文贡献的是：**面向 PX4 现有 PID+AS 的非侵入式残差观测、补偿级功率可行域投影、总加速度分配、绳长调频、飞行日志机理闭环，以及理论—SITL/HIL—实飞一致验证。**

如果论文只写成“PID 加一个带通观测器，再加一个限幅”，创新性不够；如果把上述约束分配、稳定性边界和真实实现闭合起来，才有中游北大核心论文的潜力。

## 4. 初步测试设计与有效性

共同条件：

- 绳长 `0.6 m`，负载 `0.5 kg`；
- 位置控制仍为 PX4 PID，直接 AS 参数完全一致；
- 固定模拟电池，最低剩余量均约 99.9947%，无电池告警；
- 四次 2 m 正方形平移，最大速度 0.4 m/s，1 s S 曲线加减速；
- 每次使用全新的 PX4/Gazebo 实例；
- 路线前要求摆角 RMS、当前摆角、摆速、水平速度和位置误差同时通过初始门；
- 高度真值、EKF—真值差、failsafe、路线完成、记录完整性和加速度饱和均参与自动判定。

共运行 5 架次：

- `PID + AS`：2 次，其中 1 次有效、1 次因高度真值/EKF 异常判废；
- `PID + AS + FSO-PC`：3 次，其中 2 次有效、1 次因高度真值/EKF 异常判废；
- 判废架次不进入下表性能均值，原始记录保留。

这只是首轮筛选。基线 `n=1`、候选 `n=2` 不足以做显著性检验，也不能支撑“已证明优于”的论文表述。

## 6. 功率约束和观测器是否真的工作

两次有效候选架次的 `hangfso` 日志显示：

| 机理指标 | C1 | C2 |
|---|---:|---:|
| 中心频率 | 0.643435 Hz | 0.643435 Hz |
| 补偿激活比例 | 35.13% | 33.84% |
| 功率投影触发比例 | 12.31% | 13.38% |
| 补偿 RMS | 0.00393 m/s² | 0.00355 m/s² |
| 补偿 P95 | 0.01026 m/s² | 0.00934 m/s² |
| 补偿最大值 | 0.01508 m/s² | 0.01395 m/s² |
| 投影前正功积分 | 0.001220 J/kg | 0.001348 J/kg |
| 投影后正功积分 | 3.38e-11 J/kg | 3.85e-11 J/kg |
| 投影后最大正功 | 1.05e-10 W/kg | 1.40e-10 W/kg |

因此机理判断为：

- 观测器在正确的绳长自然频率运行；
- 原始补偿确实有一部分会向摆动注能，投影器确实删除了这部分；
- 投影后新增补偿满足样本级非正功率；
- 但补偿平均只激活约 34.5%，RMS 约 `0.0037 m/s²`，最大值只达到配置上限的约 19%，所以目前的主要瓶颈不是功率约束过紧，而是可用观测量和补偿相位/幅值不足。

这里还要区分两个命题：`P_comp <= 0` 只证明新增补偿项不直接注入摆动能量，并不自动证明整个 `PID + AS + FSO-PC` 闭环稳定，也不保证位置 PID、总加速度包络及真实执行器后的总功率始终非正。论文中仍需给出闭环有界性/稳定性分析和执行后功率验证。

## 8. 当前版本的关键问题与具体修改

### 8.1 第一优先级：重做观测残差和延迟对齐

当前残差 `速度差分加速度 - 上一周期最终指令` 混合了：

- EKF 速度滤波/差分的相位滞后；
- 姿态内环、推力动态和执行器延迟；
- 机体气动阻力、建模误差；
- 吊物反作用；
- 指令包络和真实加速度之间的偏差。

它不是纯粹的“吊挂扰动”。下一版应：

1. 增加纯观测 `SHADOW` 模式，只记录不补偿；
2. 同时记录推力/姿态重构加速度、EKF 加速度、速度差分加速度和最终指令；
3. 计算自然频率处的 PSD、互谱、相干系数和相位差；
4. 识别从水平加速度指令到实际加速度的标称增益与延迟 `G_a(s)e^{-tau s}`；
5. 在残差构造或 I/Q 复增益中补偿 `tau`，不再默认“上一周期指令”等于实际加速度。

阶段通过条件建议设为：自然频率处残差与吊挂反作用具有稳定相干性，并且跨 5 次重复的相位标准差小于 15°。达不到时，不应继续盲目加大 `MC_HANG_FSO_K`。

### 8.2 第二优先级：从单一固定谐波改为可验证的频率模型

当前只有基频。文献中的 HESO 已经显式利用多谐波扰动结构，2025 年 TVUDE 也强调不同飞行阶段的扰动带宽会变化。建议：

1. 先用 SHADOW 数据判断三次谐波是否显著，再决定是否增加 `f_n + 3f_n` 双谐波，不能为复杂而复杂；
2. 对绳长误差增加小范围中心频率跟踪或频率栅格，避免 `L` 误差直接造成失谐；
3. 增加幅值/SNR/相干性门控，只有观测到可信的吊挂频带能量才激活；
4. 对起飞、快速加速、稳定巡航、减速和末端悬停使用明确的门控状态，避免用一个固定参数覆盖所有阶段。

### 8.3 第三优先级：补偿增益和相位必须预注册扫描

现有输出过弱，下一轮可做一个小而固定的筛选矩阵，例如：

- `K = {0.2, 0.4, 0.6}`；
- `BW = {0.10, 0.20, 0.30} Hz`；
- 幅值上限先固定 `0.08 m/s²`，只有确认经常撞限才比较 `{0.04, 0.08, 0.12}`；
- I/Q 补偿使用识别得到的复增益，而不是只乘一个负实数。

筛选参数和主评价指标必须在跑数据前固定。建议快速阶段每格至少 3 次，只保留能同时满足以下条件的区域：

- 摆角 RMS、峰值和能量积分三项均不劣于基线；
- 至少两项改善超过 5%；
- XY RMS 退化不超过 5%；
- 总加速度饱和率低于 5%；
- 补偿正功积分保持数值零；
- 对 `K/BW` 小扰动不发生性能排序翻转。

### 8.4 第四优先级：把功率约束从“请求级”闭合到“执行级”

现有总加速度包络主要是缩放/分配，发生率很低，本轮不会改变基本结论；但正式方法仍应补齐：

1. 分别记录 `raw compensation`、`power-projected compensation`、`post-total-envelope compensation`；
2. 用姿态/推力重构的实际水平加速度估计“执行后的补偿功率”；
3. 在摆速接近零时使用连续死区或软投影，减少半空间边界切换；
4. 推导在有界观测误差、幅值/变化率约束及基线 PID+AS 输入到状态稳定条件下的闭环有界性；
5. 明确证明的是“新增补偿不增加摆动储能”还是“总控制使储能单调下降”，不能混用两个结论。

### 8.5 第五优先级：重做正式实验矩阵

本轮的最大数据缺陷是样本数和初始条件不完全匹配。正式验证建议：

1. `PID+AS` 与 `PID+AS+FSO-PC` 随机交错，每组至少 10 次有效重复；快速筛选阶段至少 5 次；
2. 用统一的主动初始摆角/相位注入，而不是只要求低于阈值；
3. 绳长至少 `{0.4, 0.6, 0.8 m}`，质量至少 `{0.3, 0.5, 0.7 kg}`；
4. 覆盖标称路线、外部风/水平力、绳长模型误差、传感噪声、不同加减速度和初始摆动；
5. 增加无吊物或极小摆动工况，证明模块不会制造周期激励；
6. 报告 95% 置信区间、效应量和逐次原始值，不只报告最好一次；
7. 完成 SITL 后做 HIL，再做至少同矩阵子集的真实飞行。只有仿真没有实飞，对当前同类论文竞争力不足。

推荐消融：

| 组别 | 用途 |
|---|---|
| PID | 基础位置控制参考 |
| PID + AS | 当前强基线 |
| PID + AS + FSO（仅 SHADOW） | 证明频率与相位观测可信，不改变控制 |
| PID + AS + FSO（无 PC，仅仿真低增益） | 分离功率投影的影响 |
| PID + AS + FSO-PC | 完整候选 |
| PID + AS + 失谐 FSO-PC | 证明收益确来自绳长自然频率选择，而非一般附加阻尼 |

## 9. 对论文主线的建议

建议的论文题目逻辑不是“把 LADRC/ESO 换一个名字”，而是：

> 面向 PX4 吊挂运输的频率选择性扰动补偿与能量安全投影：在保留原生位置 PID 和直接抗摆阻尼的条件下，利用绳长调频的残差观测器抑制窄带吊挂反作用，并通过补偿功率可行域保证新增补偿不向摆动注能。

要达到中游北大核心论文的可信程度，至少需要四块完整证据：

1. 自然频率处的观测误差、相位和频率失谐分析；
2. 补偿功率约束与闭环有界性/稳定性推导；
3. 相对 `PID+AS` 的严格消融和统计重复；
4. HIL 或实飞验证，以及绳长/质量/外扰鲁棒性。
