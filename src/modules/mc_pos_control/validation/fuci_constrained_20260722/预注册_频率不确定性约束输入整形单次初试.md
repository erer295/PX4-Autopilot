# ZD680频率不确定性约束输入整形单次初试预注册

冻结时间：2026-07-22，代码改动和SITL出数前。

## 1. 固定方法

- 保留PX4 PID＋能量AS＋模式6协调器，不改PID、AS和HESO/RLS参数；
- 只将上次“标称频率三脉冲ZVD”替换为“频率区间指定不灵敏度约束三脉冲整形”；
- HESO/RLS仍只做影子估计，不强行在线改变脉冲，不直接补偿，AS不放大。

## 2. 冻结约束设计

小摆角线性模型的有效频率比定义为`rho = omega_actual / omega_nominal`。根据上轮飞行FFT频率比1.109/1.191，本次不确定区间冻结为：

- `rho in [0.90, 1.20]`；
- 区间稠密网格上最坏归一化残余振动 `max V(rho) <= 0.10`；
- 标称频率残余振动 `V(1.0) <= 0.03`；
- 脉冲权重非负、权重和为1、脉冲时刻递增；
- 2 m/6 s等总时长S曲线的离线峰值速度不高于0.54 m/s，峰值加速度不高于0.45 m/s²；
- 在满足上述约束的候选中，以原6 s任务轨迹的RMS/峰值指令偏差为主目标选取一组，正式飞行后不再换参数。

## 3. 单次试验

- 模式：`STD_L06_PID_AS_UCIS_FUCI`；
- 绳长0.6 m，载荷0.5 kg，四方2 m/6 s，段间保持5 s，末段保持10 s；
- 只运行1次，无效也不追加；
- 对照使用2026-07-22已冻结的C1/C2完整方法均值，不重跑基线。

## 4. 初步判据

- 必须严格有效、无failsafe，模式6选择率为100%；
- 离线频率区间、残余振动、权重、速度和加速度约束全部通过；
- 原任务时间参考XY RMS相对旧C均值至少降低15%；
- 摆角RMS和能量相对旧C均值不恶化超过25%；
- jerk P95相对旧C均值不恶化超过10%；
- AS正功积分为0，直接HESO补偿为0，AS实现权限不超过1。

单次试验只判断值得继续/需要重构，不用于宣称统计显著或论文方法已最终成立。
