# ZD680 吊挂无人机 W10 与 E-VFB 自动结构验证报告

日期：2026-07-21  
性质：结构完整性与因果筛选实验，不是论文最终重复统计数据  
标准工况：0.6 m 绳长、0.5 kg 负载、无外扰、2 m 正方形路径、0.4 m/s、TD OFF、固定模拟电池

## 1. 一句话结论

W10 确认了 EKF–ESO 速度观测误差支路会给 nominal 注入摆动能量，但取消该支路后摆角 RMS 只改善 3.00%，摆动能量积分反而轻微增加 0.034%，因此它不是当前完整方案落后于 PID+AS 的主要或唯一原因；W10 未通过阶段 1 门槛，E-VFB 按任务书没有实施。随后执行的 PID+AS+PAS 备用路线也没有达到 10% 摆角或 15% 能量改善门槛，且两次均因 52 ms 传感器时序间隔而无效。

唯一决策枚举：

```text
C_STOP_LADRC_RESCUE_SWITCH_TO_PID_AS_PAS
```

该枚举表示任务书规定的 LADRC 救援路线已经停止并已转测 PID+AS+PAS。备用路线本身也未证明优越，因此本轮结束后的工程基线仍应保持 `PID+AS`，不冻结 W10、E-VFB 或 PID+AS+PAS。

## 2. 实际完成的工作

1. 审计了 VFB 源码、参数范围、ESO 更新、z3 补偿、摆角坐标映射和功率符号。
2. 使用历史 0.6 m W05 原始日志离线复算九类功率，复现误差为 0%，确认“正功注能、负功耗能”的口径正确。
3. 扩展验证工具，新增 `STD_L06_FULL_W10_OBS_DECOUPLE` 模式。W10 只把 nominal 的速度反馈改成纯 EKF；ESO 的 z1/z2/z3 更新、z3 扰动补偿、AS、PAS、频率功能和总包络均保留。
4. 新增 `STD_L06_PID_AS_PAS` 模式。它和 `STD_L06_PID_AS` 之间只改变 PAS：`MC_HANG_PAS_MD 0 -> 2`、`MC_HANG_PAS_POS 0 -> 1`。
5. 运行 W05/W10 严格初态配对和自动分析。
6. W10 未通过性能门槛后，遵守任务书停止 E-VFB 实现，没有继续扫描 W06～W09，也没有引入 CFO、TD 或新控制器。
7. 运行 PID+AS 基线、PID+AS+PAS 首次测试，并在首次时序无效后自动复跑一次。
8. 生成 CSV、JSON、参数快照、功率分解、时序质量和本中文报告。

修改或新增的工具文件：

- `validation_tools/zd680_vfb_recorder.py`：增加 W10 和 PID+AS+PAS 模式及独立参数表。
- `validation_tools/zd680_vfb_validation_suite.py`：让批量套件接受新模式并按模式生成冻结参数。
- `validation_tools/zd680_vfb_report.py`：增加 W10 的纯 EKF、observer_error 为零、z3 继续更新等自动检查。
- `validation_tools/zd680_w10_evfb_report.py`：汇总全部尝试，执行时序分级、门槛判断并生成无 NaN 的机器可读结果。

没有修改飞控控制律，也没有改变 `MC_PLADRC_VFB_W` 的全局默认值。W10 是测试模式参数，不是默认行为更改。

## 3. 审计结果

### 3.1 VFB 的实际定义

源码中的实际公式是：

\[
v_{fb}=(1-W)z_2+Wv_{EKF}
\]

因此：

- W=0.5：EKF 和 z2 各占一半；
- W=1.0：nominal 使用纯 EKF 速度；
- W=1.0 只消除 z2 对 nominal 速度反馈的直接影响；
- LESO 仍更新，z3 仍通过 `-z3/b0` 参与扰动补偿。

本次 W10 日志实测：`v_fb-EKF` RMS 为 0，observer_error 直接加速度峰值为 0；z3 加速度峰值 0.08546 m/s²、标准差 0.01828 m/s²，证明 z3 没有被冻结或旁路。

### 3.2 功率符号与坐标

当前功率定义为：

\[
P=-L\boldsymbol a^T\dot{\boldsymbol\theta}
\]

摆角按航向坐标投到北/东轴，`MC_HANG_SIGN_X=-1`、`MC_HANG_SIGN_Y=-1`。在此定义下：

- P>0：控制分量向摆动注入能量；
- P<0：控制分量消耗摆动能量。

历史 W05 离线复算如下，与原报告完全一致：

| 历史指标 | 复算净功 |
|---|---:|
| 全路线 observer_error | +0.066567 |
| 运动段 observer_error | +0.033339 |
| 运动段 position | -0.002297 |
| 运动段 tracking | -0.015195 |
| 运动段 nominal | +0.015848 |
| 全路线 z3 | +0.002548 |
| 全路线 AS | -0.332390 |
| 全路线 PAS | -0.048086 |
| 全路线 final | -0.185504 |

审计结论：`OFFLINE_POWER_AUDIT_OK`。轴和符号能够复现，因此 W10 闭环因果测试具备前提。

### 6.1 W10 相对 W05

| 指标 | 变化 | 解释 |
|---|---:|---|
| XY RMS | +0.15% | 基本相同，满足位置门槛 |
| 摆角 RMS | -3.00% | 有小幅改善，但远低于 10% |
| 摆角峰值 | +3.67% | 反而略差 |
| 摆动能量积分 | +0.034% | 实质不变，未达到 15% |
| 末5 s RMS | -39.55% | 末端明显改善，但单项不能替代全程门槛 |

W10 的“功率机理”通过，“整体抗摆性能”失败。不能因为末端 5 s 较好就忽略全程 RMS、峰值和能量积分。

### 6.2 W10 相对本轮 PID+AS 趋势

W10 的摆角 RMS 比 PID+AS 高 10.49%，能量积分高 24.47%，摆角峰值高 31.34%，XY RMS 高 1.53%；仅末端 5 s 比 PID+AS 低 7.69%。PID+AS 本轮有 36 ms 时序警告，因此这不是论文级严格统计，但它与既有标准工况结论方向一致：W10 没有把完整方案救到 PID+AS 之上。

### 6.3 PID+AS+PAS 备用路线

复跑相对 PID+AS 的趋势为：

- 摆角 RMS 改善 3.36%，低于 10%；
- 能量积分改善 7.07%，低于 15%；
- XY RMS 恶化 6.05%；
- 摆角峰值恶化 7.81%；
- 末5 s RMS 恶化 206.89%。

首次和复跑的方向一致：PAS 对全程 RMS 和能量只有小幅帮助，却出现较大的末端残摆代价。更重要的是，两次运行的时序均无效，所以只能报告趋势，不能将这组结果写成正式性能结论。

## 12. 为什么 W10 没有解决完整方案的问题

通俗地说，observer_error 确实是“一个踩油门的人”，但它不是唯一决定吊物怎么摆的人。把这个人请下车后：

1. nominal 的净功确实从正变负，说明原来的问题定位并非误判；
2. 轨迹加速、减速仍会激起摆动，特别是这些阶段的 final 净功仍为正；
3. 改用纯 EKF 后，闭环速度误差、相位和 AS/PAS 的工作时刻一起变化，能量从 observer_error 转移到了 nominal 及其他闭环分量；
4. 全路线 nominal 在 0.55～0.75 Hz 的频带能量反而增加，抵消了删除 observer_error 的好处；
5. 因此末端收敛变好，但全程摆角峰值和总能量没有同步变好。

这就是为什么不能只看“observer_error 归零”和“总控制净功更负”便断言物理摆动一定显著减小。闭环系统的相位和轨迹激励同样重要。

## 14. 最终结论与唯一下一步

本轮三个问题的答案是：

1. observer_error 是真实注能源，但不是完整方案落后的主要或唯一原因；
2. W10 只改善了末端残摆，没有显著改善全程摆角 RMS 和能量，也仍未优于 PID+AS；
3. 因阶段 1 失败，没有理由投入时间实现 E-VFB。备用 PAS 在 PID 基线上的趋势也不足，并有末端残摆和时序问题。

唯一建议：**停止继续救援 LADRC/W10/E-VFB，也不冻结 PID+AS+PAS；将 PID+AS 作为当前工程基线，后续有限时间只用于同一测试链上的正式重复与论文结论收缩。** 不再扫描 W 权重、WC/WO、TD 或新增复杂控制模块。
