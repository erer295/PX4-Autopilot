## 3. 已完成并保留的修复

### 3.1 Gazebo FLU 到 PX4 FRD 的坐标符号修复

Gazebo SDF 关节坐标使用 FLU 约定，而 PX4 抗摆控制内部使用 FRD。对当前 `zd680_hang` 模型，两个吊挂水平关节都必须反号：

```text
MC_HANG_SIGN_X=-1
MC_HANG_SIGN_Y=-1
```

修复前，能量抗摆控制计算上认为自己在耗能，但物理方向上实际可能向摆动补能。严格门控试验中，修复前 FREQ-25/FREQ-30 都会从小摆角逐步增长到约 20°。

修复后：

- FREQ-25 不再发散，并能在部分重复中通过严格门控；
- FREQ-30 不再发散到 20°，但仍存在 1～2°极限环；
- AS 实测功率保持非正，坐标方向与能量模型一致。

因此坐标符号是已经确认并修复的真实问题。

### 3.2 自动预设参数冻结

自动测试脚本现在显式写入 LADRC、频率调度、AS、PAS、符号和总包络参数，不再依赖上一轮遗留的 `parameters.bson`。

新增可调接口：

```text
--hang-wc-r
--hang-wo-r
--hang-wo-min
--pas-position-ratio
```

这解决了过去“相同模式名称、实际频率比和抗摆参数不同”的复现问题。

### 3.3 连续初态门控

旧流程为：

```text
满足 1 s 门控 → 固定等待 2 s → 施加 wrench
```

固定等待期间吊挂可能重新离开门限。现在改为连续满足 3 s，然后立即开始外扰：

```text
摆角 RMS ≤0.75°
摆速 RMS ≤0.06 rad/s
当前摆角 ≤0.75°
当前摆速 ≤0.06 rad/s
位置误差和速度满足要求
连续保持 3 s
```

该修改暴露了过去被提前放行掩盖的低幅极限环问题。

## 8. 当前问题清单

### P0：低幅吊挂极限环导致严格门控不能稳定通过

严重度：最高，必须首先解决。

证据：

- 无外扰摆角 RMS 约 1.07°；
- 实测主频 0.681 Hz，接近理论 0.643 Hz；
- 最长连续门控通过仅 0.319 s；
- 位置和高度保持正常。

判断：

这不是发散，而是位置闭环、LESO 补偿和弱低能量 AS 共同形成的吊挂模态残余极限环。

### P1：AS 在低能量区过弱

当前能量门控为：

```text
gate = E / MC_HANG_E_FULL
MC_HANG_E_FULL=0.02
```

最新平均能量约 0.00186，平均 gate 只有约 9%；峰值能量 0.00368 时 gate 也只有约 18%。

因此虽然 `ZETA=0.10`，真正作用到控制量上的低能量阻尼很小，AS 峰值仅约 0.012 m/s²。

### P2：PAS 存在低能量盲区

当前 `PAS_E=0.005` 高于最新能量峰值 0.00368，PAS 完全不工作。

这不是参数错误本身，因为 PAS 原本用于较明显的正功率事件；但它意味着不能指望 ACTIVE 清除约 1°的残余小摆动。

### P3：位置动态恢复仍明显弱于 PID

有效外扰试验中，ACTIVE 的恢复窗位置 RMS 约为 PID 的 1.97 倍。

但最新无外扰 XY RMS 只有 0.025 m，说明问题不是静态位置刚度不足，而是外扰后的频带冲突和控制权限协调。

### P4：不能通过整体提高 LADRC 频带解决

FREQ-30 在符号修复后不再发散，但形成约 1～2°持续极限环，60 s 内不能通过严格门控。

因此：

```text
WC_R=0.30 / WO_R=0.75 / WO_MIN=2.5
```

当前仍不可接受，更不能直接进入 FREQ-35。

### P5：硬位置权限投影改善有限且产生高 jerk

曾试验 AS＋PAS 最终硬投影：

```text
恢复窗位置 RMS       0.326 → 0.299 m
最终 jerk RMS        0.598 → 2.229 m/s³
```

同时最终正功率高于候选正功率，破坏能量协调方向。

因此该实验代码已撤回，不应直接恢复。

### P6：失败试验的日志收尾不完整

门控失败时 recorder 没有生成 metadata、validity、summary，也没有复制 ULog，只保留关节 CSV。

这会增加诊断成本，也容易让失败记录被误认为完整试验。

## 9. 预计解决方式

## 9.1 第一优先级：增强低能量 AS 阻尼

第一步不修改 LADRC、不降低 PAS 阈值、不改变 PR，只调整 AS 能量门控斜率。

建议先试：

```text
MC_HANG_E_FULL: 0.02 → 0.01
```

保持：

```text
MC_HANG_ZETA=0.10
MC_HANG_ACC_LIM=0.20
MC_HANG_ACC_SLW=2.0
MC_HANG_WC_R=0.25
MC_HANG_WO_R=0.50
MC_HANG_WO_MIN=2.0
MC_HANG_PAS_E=0.005
MC_HANG_PAS_MD=2
MC_HANG_PAS_PR=0.25
```

预计作用：

- 当前低能量区 AS 有效阻尼约提高一倍；
- AS 仍然保持功率非正；
- 不改变位置 LADRC 本体；
- 不增加总加速度上限；
- 不让 PAS 参与微小噪声区。

若 `E_FULL=0.01` 仍不能在 60 s 内通过三秒门控，再试一次：

```text
MC_HANG_E_FULL=0.005
```

按当前能量估算，AS 峰值可能从约 0.012 增至约 0.04～0.05 m/s²，仍远低于 `ACC_LIM=0.20`。

停止条件：

- 无外扰摆角反而增长；
- XY RMS 超过 0.05 m；
- 最终 jerk RMS 超过 0.4 m/s³；
- AS 出现明显正功率；
- 出现持续总包络触发。

## 9.2 第二优先级：PAS 低能量 SHADOW 诊断

只有在增强 AS 后仍存在稳定小摆动，才考虑 PAS 低能量介入。

不应直接把 ACTIVE 阈值大幅降低。先在 SHADOW 中测试：

```text
MC_HANG_PAS_MD=1
MC_HANG_PAS_E=0.0025～0.003
```

观察：

- SHADOW gate 介入率；
- 预测正功率降幅；
- 修正幅值 P95；
- 是否主要响应真实 0.64～0.68 Hz 摆动，而不是测量噪声。

只有满足以下条件才进入 ACTIVE：

```text
预测正功率下降 ≥10%
修正 P95 ≤0.03 m/s²
无高频开关
位置误差没有同步增长
```

## 9.3 第三优先级：频带分离，而不是整体加带宽

FREQ-30 已证明整体提高 `WC/WO` 会增强吊挂模态耦合。后续若要追平 PID 的位置恢复，应当把位置恢复频带与摆动频带分开：

```text
低频：保留/增强位置恢复权限
0.55～0.75 Hz：抑制对吊挂模态的周期性注能
高频：保持噪声和 jerk 限制
```

优先研究对象不是最终总输出，而是控制量分解中已确认存在正功率的：

```text
LADRC nominal
LESO disturbance selected
```

建议先做 SHADOW 频带诊断：

1. 分别计算 nominal、dist_selected 在 0.55～0.75 Hz 的幅值和功率；
2. 只对正功率分量计算候选衰减，不改变闭环；
3. 验证不会削弱 0～0.3 Hz 的位置恢复分量；
4. 取得 SHADOW 数据后再决定使用平滑带阻、扰动选择器还是能量权重。

由于现在已经获得 nominal、LESO、AS、PAS 和 final 的控制量分解数据，主动频带处理已经具备研究依据；但仍不应直接加入闭环主动陷波。

## 9.4 第四优先级：平滑位置—能量权限协调

硬投影已经证明“保留位置恢复分量”方向有一定效果，但每周期几何投影产生高 jerk。

下一版应使用连续协调权重，而不是硬切换：

```text
a_target = a_energy + w_pos × a_position_recovery
```

其中 `w_pos` 应满足：

- 随位置误差连续变化；
- 随摆动能量连续变化；
- 经过一阶滤波；
- 有独立 slew 限制；
- 最终实际功率重新计算；
- 如果位置权限与能量约束冲突，记录冲突比例而不是瞬时跳变。

建议初始 slew 不超过：

```text
0.3～0.5 m/s³
```

验收条件：

```text
位置 RMS 至少改善 15%
最终 jerk 不超过当前 ACTIVE 的 1.3 倍
最终正功率不高于候选正功率
摆角 RMS 恶化不超过 10%
```

- 使用与 `FAST2_POS_PROTECT` 完全相同的参数；
- 连续记录至少 60 s；
- 不施加 wrench；
- 输出门控通过时间、最长连续通过时间和失败原因；
- 即使失败也生成 metadata、validity、summary；
- 在 `finally` 中复制当前 ULog；
- 明确标记 `completed=false`、`wrench_applied=false`。

还应把以下参数加入显式预设和参数快照：

```text
MC_HANG_ACT_DLY
MC_HANG_ACT_ANG
MC_HANG_ACT_R
MC_HANG_ACT_T
MC_HANG_RAMP_T
MC_HANG_SAFE_A

```

最新记录与有效 ACTIVE 记录中这些参数一致，但仍应冻结，避免后续再次出现历史参数继承。

## 12. 阶段结论

当前最可靠的结论是：

> 坐标符号错误已经修复，完整方案不再发生无外扰快速注能发散；FREQ-25 下静态位置和高度控制正常，AS 的实际功率方向正确且严格耗能。但低能量区 AS 太弱、PAS 又因能量阈值完全不介入，使系统在实际吊挂固有频率附近保留约 1°的低幅极限环，导致严格初态门控不能稳定复现。

因此目前方案整体仍然可行，但还不能说已经追平或优于 PID。下一步最有效、风险最低的工作是：

1. 先增强低能量 AS 阻尼；
2. 用一次无外扰静稳试验确认；
3. 再做一次完整 ACTIVE 外扰测试；
4. 若位置动态恢复仍明显落后，进入基于控制量分解的频带分离和连续权限协调，而不是整体加带宽或硬投影。

本阶段已经把问题从“坐标是否错误、参数是否过于保守、ACTIVE 是否有用”的宽泛猜测，收敛为两个具体问题：

```text
低能量吊挂模态阻尼不足
外扰恢复时位置频带与吊挂频带协调不足
```

这两个问题可以分别验证和解决，不需要推翻现有二阶 LADRC＋能量抗摆＋频率约束＋PX4 实现框架。
